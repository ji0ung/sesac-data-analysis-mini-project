# OTA 플랫폼 검색 필터 개선을 위한 데이터 조사

> Team I 미니프로젝트 참고자료  
> 조사 목적: 호텔 공급 데이터와 사용자 탐색 행동을 활용해 위치·카테고리 기반 검색 필터 개선 가능성을 검토한다.

## 조사 결론

호텔 속성·검색 노출·필터 사용·클릭·예약을 모두 포함하는 단일 공개 데이터셋은 찾기 어렵다. 따라서 이번 프로젝트에서는 다음 역할을 분리해 검증한다.

1. **Trivago RecSys 2019**로 실제 검색·필터·정렬·노출·클릭 행동 분석
2. **Rakuten Travel 데이터**로 일본 여행 목적·동행 유형별 호텔 속성 선호 분석
3. 기존 일본 호텔 공급 데이터를 기준 마스터로 사용
4. 공개 데이터로 연결되지 않는 예약·실험 구간은 가상 데이터로 보완

### 분석 Key Question

> 공개된 OTA 행동·호텔 데이터를 이용해 위치·가격·숙소 특성 필터가 사용자의 검색 성공과 클릭 가능성을 높이는지 검증할 수 있는가?

결론적으로 **부분적으로 가능하지만, 두 공개 데이터셋의 역할을 분리하고 기존 호텔 공급 데이터와 가상 행동 데이터를 보완적으로 사용해야 한다.**

## 1. 활용 가능한 호텔 데이터셋

이번 프로젝트에서는 실제 검색·클릭 행동을 확인할 수 있는 **Trivago RecSys 2019**와 일본 여행객의 목적·동행 유형·숙소 평가를 확인할 수 있는 **Rakuten Travel Data Release**만 활용 후보로 선정한다.

| 데이터셋 | 활용 목적 | 주요 데이터 | 한계 |
|---|---|---|---|
| Trivago RecSys Challenge 2019 | 검색 노출과 클릭의 관계 및 CTR 분석 | 세션, 검색, 필터, 정렬, 노출 호텔, 가격, 호텔 상호작용, clickout | 예약 완료가 아닌 제휴 예약사이트 이동까지만 확인 가능 |
| Rakuten Travel Data Release | 일본 여행 목적·동행 유형별 호텔 속성 선호 분석 | 여행 목적, 동행자, 객실·플랜, 호텔 평가, 후기 | 검색 노출·필터 사용·클릭 데이터가 없음 |

### 1-1. Trivago RecSys Challenge 2019

Trivago 데이터는 사용자가 호텔을 검색하고 검색결과를 탐색한 뒤 특정 호텔을 클릭하는 과정을 세션 단위로 제공한다.

주요 데이터는 다음과 같다.

- 사용자·세션·행동 시각
- 목적지·POI·특정 호텔 검색
- 필터 선택과 현재 적용 필터
- 검색결과 정렬 변경
- 노출 호텔과 당시 가격
- 호텔 정보·평점·이미지·상품 상호작용
- 제휴 예약사이트로 이동한 clickout

이를 이용하면 검색결과 노출 대비 호텔 클릭 비율, 필터 사용 전후 CTR, 노출 순위별 CTR, 가격대별 CTR과 재검색 행동을 분석할 수 있다.

다만 clickout은 예약 완료가 아니므로 Booking Conversion이 아니라 **검색결과 클릭 성공 또는 상세 탐색 진입의 대리지표**로 사용해야 한다.

- [Trivago 공식 데이터 정의](https://github.com/recsyschallenge/2019/blob/master/docs/problem_definition.md)
- [Trivago 공식 벤치마크 코드](https://github.com/trivago/recsys-challenge-2019-benchmarks)

### 1-2. Rakuten Travel Data Release

Rakuten Travel 데이터는 일본 숙소와 일본 여행객의 여행 목적·동행 유형·숙소 평가를 포함한다.

주요 데이터는 다음과 같다.

- 여행 목적: 관광·출장 등
- 동행 유형: 가족·커플·혼자 등
- 호텔·객실·숙박 플랜
- 위치·객실·식사·목욕·서비스·시설 평점
- 후기 내용과 호텔 답변

CTR을 직접 계산할 수는 없지만 관광객과 출장객, 가족과 1인 여행객이 중요하게 평가하는 호텔 속성을 비교해 **세그먼트별 필터 후보와 필터 노출 순서**를 설계할 수 있다.

- [Rakuten Travel 공식 데이터 안내](https://ai.rakuten.com/rakuten-data-release/)

## 2. 검색·호텔 데이터 분석 사례

### 종합 요약

선행사례를 CTR 관점으로 종합하면 호텔 검색결과의 클릭은 다음 네 가지 요인의 영향을 받는다.

1. **검색 적합성:** 검색 목적지·POI와 호텔 위치가 얼마나 일치하는가
2. **노출 순위:** 호텔이 검색결과의 몇 번째 위치에 노출됐는가
3. **호텔 정보:** 평점·가격·프로모션·무료 취소 등의 정보가 표시됐는가
4. **탐색 기능:** 사용자가 필터와 정렬을 이용해 결과를 원하는 조건으로 좁힐 수 있는가

따라서 본 프로젝트의 Hotel Detail CTR은 다음과 같이 정의하는 것이 적절하다.

> **Hotel Detail CTR = 호텔 상세조회가 발생한 검색결과 노출 건수 ÷ 전체 유효 호텔 노출 건수**

필터 개선 효과를 확인할 때는 전체 CTR만 비교하지 않고 다음 조건을 함께 통제해야 한다.

- 검색결과 노출 순위
- 목적지와 호텔 간 거리
- 호텔 가격과 평점
- 프로모션·무료 취소 표시 여부
- 신규·기존 사용자
- 관광·출장 등 여행 목적

### 사례 요약

| 사례 | CTR 관련 핵심 내용 | 프로젝트 적용 |
|---|---|---|
| Trivago RecSys Challenge | 검색·필터·정렬·호텔 노출 후 clickout 분석 | 필터 사용 전후 CTR 비교 |
| Hotels at Fingertips | 평점·할인·프로모션·검색 순위가 클릭에 영향 | 호텔 정보와 순위를 통제한 CTR 분석 |
| What Makes Customers Click? | 무료 취소·나중 결제·청결 배지·대표 이미지가 클릭에 영향 | 검색결과 카드 정보별 CTR 비교 |
| OTA 정렬·필터 실험 | 필터가 사용자의 선택 기준과 클릭 분포를 변화시킴 | 필터 적용 전후 호텔 선택 분산 분석 |
| G2NET | 검색 목적지와 호텔의 지리적 관계를 랭킹에 반영 | 오타루·삿포로·인접지역 위치 적합성 개선 |

### 2-1. Trivago RecSys Challenge

목적지 검색, 필터 선택, 정렬 변경, 호텔 노출, 가격과 clickout을 세션 순서대로 분석할 수 있다. 특정 필터가 사용된 세션과 사용되지 않은 세션의 CTR 및 재검색률을 비교하기에 가장 적합하다.

다만 clickout은 호텔 상세조회나 예약 완료가 아니라 제휴 OTA로 이동한 행동이므로 본 프로젝트의 Hotel Detail CTR과 동일한 지표로 해석해서는 안 된다.

- [공식 데이터 정의](https://github.com/recsyschallenge/2019/blob/master/docs/problem_definition.md)
- [관련 연구](https://arxiv.org/abs/1908.00071)

### 2-2. Hotels at Fingertips

미국 지역 Expedia 클릭스트림의 39,574개 검색과 약 94만 건의 호텔 노출을 이용해 검색→클릭→예약 단계를 분석했다.

평점·할인·프로모션·브랜드·검색결과 순위가 클릭 가능성에 영향을 주었으며, 클릭 단계와 예약 단계에 영향을 미치는 정보가 서로 다르게 나타났다. 따라서 상세조회 CTR과 예약 전환율을 분리해서 분석해야 한다.

- [논문 원문 및 DOI](https://doi.org/10.1108/JHTT-03-2017-0026)

### 2-3. What Makes Customers Click?

Priceline의 호텔 검색결과 카드 3,617건을 이용해 대표 이미지, 호텔 배지, 무료 취소와 결제 조건이 클릭 행동에 미치는 영향을 분석했다.

무료 취소·나중 결제·청결·고객 선호 배지는 호텔을 클릭하기 전에 판단할 수 있는 정보 신호로 작용했다. 따라서 결과 카드에 표시된 정보도 impression 데이터에 포함해야 한다.

- [ScienceDirect 논문 페이지](https://www.sciencedirect.com/science/article/pii/S027843192300155X)
- [DOI](https://doi.org/10.1016/j.ijhm.2023.103581)

### 2-4. OTA 정렬·필터 기능 실험

사용자 1,492명을 대상으로 정렬·필터 기능이 호텔 선택에 미치는 영향을 실험했다.

가격 필터를 제공하면 저렴한 객실 선택이 증가하고 평점 필터를 제공하면 고평점 객실 선택이 증가했다. 또한 선택이 검색결과 상위 호텔에만 집중되지 않고 결과 전반으로 분산됐다.

- [논문 정보와 초록](https://research.vu.nl/en/publications/from-ota-interface-design-to-hotels-revenues-the-impact-of-sortin/)
- [무료 PDF](https://www.universiteitleiden.nl/binaries/content/assets/rechtsgeleerdheid/fiscaal-en-economische-vakken/belastingrecht/artikelrest.pdf)

### 2-5. G2NET 지리정보 기반 호텔 검색 랭킹

G2NET은 사용자 위치, 검색 목적지와 호텔 위치 사이의 지리적 관계를 검색 순위에 반영하는 호텔 검색 랭킹 연구다.

본 프로젝트에서는 행정구역 일치 여부뿐 아니라 목적지 중심 거리, 역·관광지까지의 거리와 인접 지역 여부를 사용해 위치 적합성을 계산하는 근거로 활용할 수 있다.

- [G2NET 논문 DOI](https://doi.org/10.1145/3534678.3539025)

## 3. 도움이 될 기능 관련 아티클과 자료

### 종합 요약

기능적인 관점에서 필요한 것은 많은 필터를 제공하는 것이 아니라 다음 기능을 데이터로 검증하는 것이다.

- 검색·필터·정렬·노출·클릭 이벤트 수집
- 목적지와 호텔 위치의 적합성 계산
- 클릭 이력과 호텔 속성을 결합한 검색 순위
- 신규 호텔의 클릭 데이터 부족 문제 보완
- 필터 개선 전후 CTR을 비교하는 대조실험

UX 화면 배치나 사용성 평가는 연구 범위에서 제외하고, **검색결과 생성·필터링·랭킹·클릭 측정 기능**에 한정한다.

### 상세 아티클과 자료

#### Trivago 검색 이벤트 데이터 구조

검색, 필터, 정렬, 노출 호텔, 가격과 clickout을 세션 순서로 제공한다. 가상 검색 행동 데이터의 이벤트 종류와 연결키를 설계할 때 직접 참고할 수 있다.  
출처: [Trivago 공식 데이터 정의](https://github.com/recsyschallenge/2019/blob/master/docs/problem_definition.md)

#### Hotel2vec: 호텔 속성을 결합한 추천

클릭 이력에 호텔 유형, 성급, 평점, 편의시설과 위치정보를 결합해 호텔 간 유사성과 추천 순위를 계산한다. 신규 호텔처럼 클릭 이력이 부족한 숙소도 공급 속성으로 보완할 수 있다.  
출처: [Hotel2vec 무료 원문](https://arxiv.org/abs/1910.03943)

#### G2NET: 위치 적합성 기반 호텔 랭킹

사용자 위치, 검색 목적지와 호텔 위치의 관계를 학습해 검색결과 순위를 계산한다. 오타루 검색에서 오타루·삿포로·인접지역 호텔의 노출 순서를 결정하는 기능에 활용할 수 있다.  
출처: [G2NET 논문](https://doi.org/10.1145/3534678.3539025)

#### Airbnb 검색 개인화와 지도 랭킹

과거 예약과 최근 탐색을 사용자 선호 신호로 사용하고, 지도에서 보고 있는 지역을 검색 랭킹에 반영한다. 지도 이동·확대·재검색을 별도 행동 이벤트로 수집해야 한다는 근거가 된다.  
출처: [Airbnb 지도 검색 랭킹](https://airbnb.tech/ai-ml/improving-search-ranking-for-maps/) · [검색 개인화 연구](https://www.kdd.org/kdd2018/accepted-papers/view/real-time-personalization-using-embeddings-for-search-ranking-at-airbnb)

#### Booking.com 온라인 대조실험

검색 기능 변경을 실험군과 대조군으로 나누고 CTR·예약 전환·가드레일 지표를 함께 검증하는 운영체계를 설명한다. 필터 개선 효과를 단순 전후 비교가 아닌 experiment_assignment 기반으로 측정하는 근거다.  
출처: [Booking.com 온라인 실험 연구](https://arxiv.org/abs/1710.08217)

## 4. 프로젝트 적용 권고안

| 분석 영역 | 권장 데이터 |
|---|---|
| 실제 검색·필터·클릭 행동 | Trivago RecSys 2019 |
| 일본 여행 목적·동행 유형 | Rakuten Travel Data Release |
| 일본 호텔 공급 속성 | 기존 `Hotellist_supplier_japan_clean.xlsx` |
| 예약 전환 | 가상 `booking_funnel` |
| 실험군·대조군 | 가상 `experiment_assignment` |

Trivago의 익명 `item_id`와 현재 일본 호텔 데이터의 `hotel_id`는 직접 연결할 수 없다. 따라서 다음처럼 두 분석을 분리한다.

- **실데이터 검증:** Trivago로 필터 사용과 검색 노출·클릭의 관계 및 CTR 분석
- **일본 적용 검증:** 기존 일본 호텔 공급 데이터에 가상 사용자 세션을 결합해 위치·카테고리 필터 개선 효과 시뮬레이션

## 추가 확인이 필요한 사항

Rakuten Travel 데이터는 대학·연구 목적의 신청과 승인이 필요하다. 프로젝트 기간 안에 사용할 수 없다면 Rakuten 데이터는 세그먼트와 필터 후보 설계의 참고자료로만 사용하고, 실제 분석은 Trivago와 가상 데이터로 진행한다.
