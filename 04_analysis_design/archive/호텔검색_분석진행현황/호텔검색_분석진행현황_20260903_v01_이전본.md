## 3. 지표 해석에서 수정한 사항

### 3.1 호텔 클릭과 상세조회

`hotel_click` 231건과 `hotel_detail_view` 231건은 대상 키 조합이 같은 중복 기록으로 검토됐다. 두 건수를 합산하거나 별도 KPI로 병렬 해석하지 않는다. 발표와 대시보드에서는 `호텔 상세진입 231건`으로 통합한다.

### 3.2 검색 대비 예약 비율

`36 / 296 = 12.16%`는 숫자상 맞지만, 예약 테이블에 검색별 예약을 직접 연결하는 `search_id`가 없다. 따라서 정확한 `검색 → 예약 전환율`이 아니라 전체 건수의 단순 관측 비율로만 적어야 한다. 핵심 전환 KPI에서는 제외하는 것이 안전하다.

### 3.3 예약 시작 대비 완료 비율

`36 / 45 = 80.0%`는 이벤트 건수 기준 관측 비율로 사용할 수 있다. 다만 개별 사용자나 개별 예약의 연속된 경로를 확인한 값은 아니므로 `사용자 전환율`로 부르지 않는다.

### 3.4 노출 대비 클릭 비율

`231 / 8,555 ≈ 2.70%`는 노출 이벤트 대비 상세진입 이벤트의 관측 비율이다. 사용자와 검색 단위의 중복을 제거하지 않았으므로 `정확한 사용자 CTR`로 표현하지 않는다.

## 4. 33일차 실습 답안으로 정리한 초안

다음 세 건을 `결과 → 발견 → 인사이트`로 정리했다.

1. 예약 시작 45건 중 완료 36건: 이벤트 건수 기준 완료 비율 80.0%, 미완료 9건
2. 호텔 노출 8,555건과 상세진입 231건: 노출 대비 상세진입 이벤트 비율 약 2.70%
3. 평점순 검색 230건: 전체 296건의 약 77.7%

이 초안에서 원인은 확정하지 않았다. 가격·정렬·화면 표현·로그 누락 등은 모두 검증할 `원인 후보`로만 남겨 두었다. 또한 평점순이 기본값인지 사용자가 직접 선택한 것인지 확인하지 못했으므로, 평점순 사용이 예약 증가의 원인이라고 해석하지 않았다.

## 6. G그룹 성공 기준

### 6.1 직접 상호작용 성공 세션

> 첫 검색에서 결과를 확보한 후, 재검색하기 전에 유효 상호작이 하나 이상 발생한 세션

### 6.2 재검색 후 상호작용 성공 세션

> 첫 검색에서는 유효 상호작이 없었지만, 조건을 바꿔 재검색한 뒤 유효 상호작이 하나 이상 발생한 세션

### 6.3 상호작용 없음 세션

> 검색 결과가 노출됐지만 세션이 끝날 때까지 유효 상호작이 발생하지 않은 세션

유효 상호작 후보는 다음과 같다.

- 호텔 상세진입: `hotel_detail_view` (`hotel_click`과 중복 처리)
- 찜: `wishlist_add`
- 객실 선택: `room_select`
- 장바구니 추가: `cart_add`
- 예약 시작: `booking_start`
- 예약 완료: `booking_complete`

한 세션에서 여러 상호작이 발생해도 성공 세션은 1개로 계산한다. 예약 완료는 검색 세션과 연결할 수 있는 경우에만 성공 판정에 포함하고, 연결되지 않는 예약은 참고 지표로 남긴다.

## 9. 아직 확정하면 안 되는 내용

- `27/43 = 62.8%`는 기존 문서에서 제시된 값이지만, 새로 합의한 성공 정의로 재계산하지 않았다.
- 검색 결과가 나왔다는 사실만으로 성공 세션이라고 판정하지 않는다.
- 상세진입, 찜, 객실 선택, 예약 완료는 행동 강도가 다르므로 단계별 KPI를 따로 유지한다.
- `result_score`, `result_rank`, `price_rank`는 실험용 값이므로 특정 정렬 방식의 인과적 효과를 주장하는 근거로 사용하지 않는다.
- 예약 데이터는 참고 시나리오 성격이며, 검색 세션과 연결되지 않은 예약을 검색 성공률에 포함하지 않는다.
