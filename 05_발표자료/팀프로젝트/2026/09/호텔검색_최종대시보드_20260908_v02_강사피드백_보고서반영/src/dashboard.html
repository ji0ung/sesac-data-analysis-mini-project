호텔 검색 결과가 없을 때,
어떻게 다시 찾도록 도울까?

주제

호텔을 검색하는 과정에서 결과가 없는 상황과 이후의 검색 행동을 분석합니다. 사용자가 어떤 조건으로 검색하고, 무엇을 바꿔 다시 검색하며, 결과를 찾았는지 살펴봅니다.

문제

검색을 다시 한다고 해서 원하는 결과를 찾는 것은 아닙니다. 조건을 유지한 채 검색을 반복하거나, 조건을 바꿔도 결과가 없는 경험이 이어질 수 있습니다. 검색량뿐 아니라 결과 없음 이후의 회복 과정을 함께 봐야 합니다.

분석 목적

사용자의 검색 조건과 경험을 비교해 반복 실패가 발생하는 지점을 찾고, 조건 완화와 지역 확대 등 개선안을 검토합니다. 합성 시뮬레이션은 개선 가정을 탐색하는 자료로 사용하며, 실제 효과는 별도의 사용자 실험으로 검증합니다.

검색결과 4개 · 세션 단위

첫 검색의 결과 유무를 먼저 나눈 뒤, 첫 결과가 있으면 세션 내 호텔 클릭 유무, 첫 결과가 없으면 후속 검색의 결과 회복 유무로 분류합니다.

중복 없음: 검색이 있는 세션마다 정확히 1개 성과군. 전체 기준 630 + 231 + 92 + 47 = 1,000세션입니다.

판정 시점·예외·필터 적용

세션 안에서 search_time → search_id 오름차순으로 정렬합니다. 같은 사용자가 여러 세션을 가지면 성과군은 세션마다 달라질 수 있습니다. 한 세션의 전체 검색 기록으로 판정한 후, 세션 시작 월과 성과군으로 필터링합니다.

첫 검색 결과가 있으면 이후 0건 검색을 했더라도 SG1 또는 SG2입니다. 첫 검색이 0건이면 클릭 여부와 관계없이 후속 검색에서 한 번이라도 결과를 찾으면 SG3입니다. 후속 검색이 아예 없어도 SG4이며, 이를 이탈이나 구매 실패로 단정하지 않습니다.

의도군과 성과군은 서로 다른 축입니다. 성과군은 행동 후 판정하므로 대조군·실험군 또는 실험 전 의도군으로 사용하지 않습니다. 기본 퍼널과 모든 관측 집계는 전체 기간·전체 성과군 기준입니다.

발표 대본 · 가설과 분모 구분

원 문서는 가설 번호를 지정하지 않습니다. 기존 보고서와 연결하기 위해 전체 조건 완화를 H1, 의도별 차이를 H2, 지역 확대를 H5로 대응했습니다. A-1은 전체와 두 의도군의 비교 차트, D-1은 비교 차트와 단계 흐름을 제시합니다. 현재 화면은 그 네 가지 질문을 세 가설로 묶었습니다.

A-1 분모는 0건 후 후속 검색, D-1 분모는 지역 변경 후속 검색입니다. D-1 지역 변경 여부는 처치 이후 행동일 수 있어 이 조건부 회복률만으로 전체 배정 대상의 인과효과를 판단하지 않습니다. 원본 10/24는 탐색적 관측 기준이며 대조군 실험군 결과가 아닙니다. 단계별 사람·세션·검색 단위 및 관찰창은 원 실험자료와 맞춰야 합니다.

다음 검색 없음 ≠ 사용자 이탈. 원하는 호텔을 찾았거나 상세 페이지를 탐색 중이거나 나중에 돌아올 가능성을 구분할 수 없습니다. 따라서 검색 후 종료 비율을 실제 사용자 이탈률로 해석하지 않습니다.

향후 사용자 단위 이탈·리텐션 분석에는 비활성 시간 기준, 관찰창, 세션 간 사용자 연결, 종료·상세 탐색·재방문 이벤트 정의가 필요합니다. 현재 합성 데이터는 사용자당 1세션, 최대 31검색 생성 제한도 있습니다.

발표 대본 · 04 · 핵심 발견·의사결정

기본 수치는 전체 데이터 기준입니다. 필터를 바꿨다면 화면의 수치를 사용하세요.

발견은 세 가지입니다. 첫째, 재검색은 많이 하지만 바로 결과를 찾는 비율은 낮습니다. 둘째, 지역 변경·조건 완화 등 행동에 따라 회복률 차이가 관측됩니다. 셋째, 동일 조건 반복에서는 회복이 관측되지 않았습니다.

이 결과는 어떤 개선안을 검토할지 알려주는 관측 근거입니다. 합성 확장본의 차이를 실제 제안의 인과효과로 단정하지 않습니다. 채택·추가 실험·중단 판단은 기존 A/B의 효과, 불확실성, 보호지표와 연결해야 합니다.

현재 완료한 것은 1,000명 집계와 최종 보고서의 10,000명 합성 A/B 결과 연결입니다. 교육·발표·탐색용 제한 사용이며 실제 기능 효과와 배포 판단은 보류합니다.
