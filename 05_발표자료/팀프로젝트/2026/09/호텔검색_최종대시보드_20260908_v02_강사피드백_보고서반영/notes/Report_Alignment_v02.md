탐색용 분석 handoff 및 analysis_effects/analysis_segments를 data/exploratory_10000.json에 출처 SHA와 함께 연결했습니다. 빌드 시 scripts/exploratory.py가 전체 8개 지표, 14개 조건군, C/T 전이 흐름, 가설 근거를 생성합니다. 실제 SQLite는 로컬 Git LFS 포인터여서 직접 DB 재계산은 하지 않았습니다. 노출/선택·의도군은 산출 불가로 표시합니다. 01 상단은 10,000명 합계, 하단은 명시된 1,000명 참고 기준선입니다.

## 검색 경험 중심 전체 현황

최신 DB LFS 객체를 다운로드하고 SHA-256 일치를 확인해 읽기 전용 직접 집계로 교체했습니다. data/overview_10000.json, scripts/aggregate_overview.py, scripts/overview.py가 관리합니다. 전체 현황의 실험군 비교와 1,000명 상세는 표시하지 않습니다. 기존 JS/발표 참조 호환을 위한 원래 DOM은 숨김으로 보존했습니다. 보고서의 65,355검색·30,614건 0건·6,366명 0건 경험·4,936명 최종 회복과 검산했습니다. 검색 경험 4개 군은 기존 첫 검색·클릭·후속 회복 정의를 최신 DB에 적용해 재집계했으며 보고서의 SG 명칭으로 전용하지 않았습니다.

## 05 KPI와 세그먼트 경로

05는 S→P→D→B의 고유 검색 단위 모델입니다. P=S(1−z), D=P×d, B=D×b. 예약 b는 사용자 입력이며 미입력은 미측정입니다. 목표 예약에서 S를 역산하고 상세 진입 비악화·검색 부담 한계를 계획용 가드레일로 검사합니다. 검색 경로 군은 첫 결과 있음 8,642명, 첫 0건 후 재시도·회복 1,095명, 재시도·미회복 217명, 재시도 없이 종료 46명입니다. 순번별 도달·다음검색없음·재검색·즉시회복 분자와 분모를 별도 저장하고 분모 0은 결측으로 그립니다. 검색어 5개의 주제군은 명시된 규칙 가분류이며 6개 행동 의도군을 대체하지 않습니다.
