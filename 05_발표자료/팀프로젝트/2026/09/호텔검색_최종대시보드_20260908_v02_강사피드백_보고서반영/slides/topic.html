일본 여행객의 호텔 검색 효율 개선

검색 의도와 노출 결과를 비교하고, 결과가 없을 때 다시 숙소를 찾는 과정을 분석합니다.

왜 이 주제를 선택했는가?

원하는 조건으로 검색해도 숙소를 찾지 못할 때, 어떤 조건에서 탐색이 막히고 사용자가 어떻게 다시 찾는지 함께 진단하기 위해서입니다.

무엇을 확인하는가?

어떤 조건에서 결과 없음이 발생하며, 조건 완화·지역 변경 뒤에 결과를 다시 찾는가?

어디까지 분석하는가?

검색 조건 → 노출 결과 → 재검색 → 회복·클릭을 연결합니다. 현재 발표는 결과 없음 이후의 검색 회복에 초점을 둡니다.

결과를 어떻게 활용하는가?

의도별 조건 완화와 지역 확대의 개선 우선순위를 정하고, A/B 결과를 연결해 효과를 검증합니다.

발표 대본 · 기획 배경과 범위

초기 기획은 검색어·필터·객실 조건과 실제 노출의 적합도, 결과 순위, 후속 행동과 예약 전환을 함께 보는 대시보드였습니다. 현재는 확보된 검색·클릭 기록으로 확인할 수 있는 검색 회복에 초점을 맞췄습니다. 예약 성공이나 이탈을 현재 지표만으로 단정하지 않습니다.

SEARCH·SEARCH_FILTER의 조건을 SEARCH_RESULT의 노출, EVENT의 행동과 연결합니다. 검색 조건은 관측값이며 잠재 의도를 완전히 설명하지 않습니다. 객실 옵션별 분석에는 값의 표준화가 먼저 필요합니다. 관측 차이는 개선 후보를 찾는 근거로 사용하며 실제 제안의 인과효과는 별도 A/B 결과로 확인합니다.
