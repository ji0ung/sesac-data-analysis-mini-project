# 35일차 오늘 실습 기준 · 대시보드 발표 구조 참고안

## 오늘 실습 목표

34일차 상위 전략을 대시보드 v2.0 화면으로 옮긴다. 확인되지 않은 수치를 추가하지 않고, 기존 화면을 진단해 불필요한 요소를 제거한 뒤 핵심 차트와 KPI를 다시 배치한다.

대상자는 **검색 효율을 개선하는 서비스 기획자·검색/추천 운영 담당자·데이터 분석가**다. 화면이 돕는 결정은 **결과 없음 이후 어느 단계가 가장 큰 병목이며, 어떤 개선안을 먼저 검증할 것인가**이다.

## 오늘 실습의 내용 구조

### 1. 진단과 제거

대시보드를 목적, 사용자, 3초 인지, 핵심 지표, 차트 수, 지표 정의, 필터, 빈 공간의 8개 기준으로 진단한다.

- 질문형 제목을 결론형 제목으로 교체한다.
- 같은 질문에 답하는 중복 차트는 하나만 남긴다.
- 분모가 다른 비율을 같은 축에 놓지 않는다.
- 쓰지 않는 필터와 내용 없는 템플릿을 제거한다.
- `성과군 여정` 표현은 팀 회의 결정에 따라 제거한다.
- 미확정 수치는 `0%`가 아니라 `데이터 미연결` 또는 `검증 불가`로 표시한다.

### 2. 결론형 제목과 핵심 메시지

> **재검색은 이어지지만, 즉시 회복 17.1%에서 가장 크게 빠집니다.**

화면을 3초만 봐도 `결과 없음 147건 → 후속 검색 140건 → 즉시 회복 24건`을 읽을 수 있어야 한다.

### 3. 상단 핵심 KPI

| KPI | 값 | 분자·분모 | 단위 |
|---|---:|---|---|
| 검색 결과 없음률 | 49.7% | 147 / 296 | 검색 |
| 0건 후 후속 검색률 | 95.2% | 140 / 147 | 검색 전이 |
| 즉시 회복률 | 17.1% | 24 / 140 | 검색 전이 |
| H-SEARCH 상세 진입률 | 19.5% | 29 / 149 | 고유 검색 |

Card H는 오늘 최종 검토의견을 따른다.

- 정본: `H-SEARCH = 상세 진입이 1회 이상 있었던 고유 검색 / 결과가 있었던 고유 검색 = 29/149 = 19.5%`
- `110`은 상세조회 이벤트 행 수이므로 `H-EVENT = 110행`으로 별도 관리한다.
- `110/149 = 73.8%`는 이벤트와 검색 단위를 섞은 초기 폐기값이다.

### 4. 오늘 요구된 핵심 차트

#### A-1 차트 1 · 조건 완화 전체 효과

- 질문: 맞춤 조건 완화를 받은 실험군의 결과 회복률이 대조군보다 높은가?
- 시각화: 대조군·실험군 묶은 세로 막대
- 축: 0~100%, 절단 없음
- 지표: 결과가 1건 이상 나온 후속 검색 / 0건 후 후속 검색
- 실제 배정과 성과가 연결되지 않았다면 수치 대신 `검증 불가`와 사유를 표시한다.

#### A-1 차트 2 · 의도군별 조건 완화 효과

- 질문: 조건 완화 효과가 `budget_flexible`과 `option_count_flexible`에서 다른가?
- 시각화: 의도군별 대조군·실험군 묶은 세로 막대
- 각 의도군 안에서 동일한 분모를 사용한다.
- `intent_segment`가 검색·성과에 연결되지 않으면 효과를 계산하지 않는다.

#### D-1 차트 1 · 지역 확대 효과

- 질문: 위치 유연형에게 인접·대체 지역을 제안하면 결과 회복률이 높아지는가?
- 시각화: 대조군·실험군 묶은 세로 막대
- 범위: 일본의 현재 5개 도시 안에서 제안
- 원본 참고값: 자발적 지역 변경 후 회복 10/24 = 41.7%
- 41.7%는 관측 비교이며 제안의 A/B 효과가 아니다.

#### D-1 차트 2 · 지역 확대 단계 흐름

- 질문: 지역 확대 제안이 어느 단계에서 가장 많이 줄어드는가?
- 시각화: 단계 막대 또는 퍼널
- 단계: 제안 노출 → 제안 선택 → 지역 변경 → 결과 회복
- 단계마다 중복 제거 기준, 관찰창, 분모를 표시한다.

### 5. 권장 화면 배치

1. 결론형 제목과 대상자
2. 핵심 KPI 3개와 분자·분모
3. 결과 없음 → 후속 검색 → 즉시 회복 퍼널
4. 조건별 정렬 막대
5. SG1~SG4 세션 결과 분포
6. A-1 조건 완화 핵심 차트 2개
7. D-1 지역 확대 핵심 차트 2개
8. 지표 정의·출처·기간·표본
9. 한계와 추가 필요 데이터

검색 296, 결과 있음 검색 149, 세션 43, 사용자 41, 전이 140을 같은 분모처럼 섞지 않는다.

### 7. 발표 캡처 설명 순서

1. 화면의 대상자와 결정
2. 3초 메시지: 재검색보다 즉시 회복이 병목
3. KPI의 분자·분모와 분석 단위
4. 퍼널에서 가장 크게 줄어드는 단계
5. A-1과 D-1 개선 전략
6. 실제 A/B 검증 가능 여부와 사유
7. 수정 전후 무엇이 나아졌는지
8. 추가로 필요한 데이터

### 8. 오늘 실습의 해석 제한

- 10,000명 데이터는 교육·발표·탐색용 합성 시뮬레이션이다.
- strict 검증은 16/20으로 요구 기준 18/20에 미달하여 HOLD다.
- 0건률 감소와 즉시 회복 증가는 생성 설정에 넣은 가정의 작동 확인이다.
- 실제 서비스 A/B 인과효과로 말하지 않는다.
- 검색의도 6개는 문서상 정의다. `intent_segment`가 실제 검색 결과와 연결되지 않았다면 의도별 효과 분석은 불가하다.
- 다음 검색이 없다는 것만으로 사용자 이탈을 확정할 수 없다.
- 예약 KPI는 연결 검증이 끝나지 않았으므로 현재 화면에서 제외한다.
