# 10,000명 합성 A/B 시뮬레이션 사용 제한

출처: 사용자가 대화에 제공한 검토 내용과 수치. 원 검증 로그를 이번 편집에서 재실행하지 않았습니다. 기존 대시보드의 1,000명 집계와 별도입니다.

- 품질 상태: `CALIBRATION_VALIDATION=HOLD` 유지.
- 별도 사용 기록: 기준선 재현 조건 일부 미충족을 수용한 탐색용 데이터.
- 범위: 학습·발표용 A/B 시뮬레이션, 대시보드 구성, 세그먼트 탐색, 시나리오 비교.
- 해석 제한: 실제 서비스 개선율 확정, 원본 신뢰구간 축소, 실서비스 기능 효과 검증의 근거로 사용하지 않음.
- 기준 49.7681%, pooled 50.2233%, 제공 차이 +0.4551%p. 표시값 차감은 +0.4552%p이므로 원래 정밀도 확인 필요.
- 검색 10,000회 × 0.4551/100 = 45.51 ≈ 46건. 10,000명 생성 결과의 예측이 아님.
- 16/20은 실행 기준 충족 수, 4 seed는 상한 초과. 행 오류율 20%가 아님.
- 표본 확대가 체계적 차이를 제거하지 않음. 신뢰구간·예측구간·seed 범위를 구분하며 원인을 분산 문제로 확정하지 않음.

## 제공된 환산표

공통 분모·arm 범위·기간이 미확인인 참고값입니다. Card H-SEARCH, Z 경험 사용자 정의는 원 검증표 연결 필요. Seed 범위는 신뢰구간으로 해석하지 않습니다.

| 검색 0건 | +0.4551%p | 약 +157건 | 약 −343~+633건 |
| 후속검색 | −0.0847%p | 약 −15건 | 약 −107~+64건 |
| 즉시 회복 | −0.1870%p | 약 −31건 | 약 −228~+124건 |

## 문제와 대응

| 현재 상태 | 해석 위험 | 대응 |
| --- | --- | --- |
| 0건률 기준선 차이 | 실패 검색·개선 대상 규모 과대평가 가능 | 기준·대조군·실험군의 비율과 %p 차이 공개 |
| Seed별 실행 변동 | 한 번의 결과를 대표 효과로 단정하기 어려움 | 고정 seed 실행과 기존 다중-seed 결과를 함께 제시 |
| 표본 확대의 한계 | 체계적 차이를 좁은 구간이 가릴 수 있음 | 모형 조건부 시뮬레이션 구간으로 표시 |
| 0건 이후 treatment 적용 | 노출 대상·실패 이력에 따라 효과 크기가 달라짐 | 노출 → 수용 → 조건 변경 → 성과 연결, 과대·과소 방향 단정 금지 |
| 세부 세그먼트 차이 | 전체 평균이 작은 차이를 보여도 특정 조건에 편향 집중 가능 | 가격·옵션·지역 등 사전 조건별 분모와 기준선 차이 공개 |
| 평가 DB의 무결성·clone PASS | 5,000명/arm 확대 시 새 오류 가능 | 실제 생성한 10,000명 DB를 다시 전수 검수 |
| 가정 기반 treatment | 설정한 행동확률에 개선 결과가 의존 | 기존 세 시나리오 민감도 제시, 실제 실험과 구분 |
| 원래 품질 게이트 HOLD | 제한 사용을 품질 승인으로 오해할 수 있음 | HOLD와 제한 사용 사유를 동시에 보존 |
