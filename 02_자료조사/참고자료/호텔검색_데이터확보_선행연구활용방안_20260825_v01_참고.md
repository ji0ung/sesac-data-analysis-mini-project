# 데이터 확보 및 선행 연구 활용 방안

## 5줄 요약

1. 실제 데이터가 부족해 가상 데이터 의존도를 낮출 수 있는 수집 방안을 검토한다.
2. 여행 플랫폼의 공개 검색 로그, 클래스 구성원 및 외부 커뮤니티 설문을 활용한다.
3. 설문을 통해 여행 목적, 검색 행동, 호텔 선택 기준 및 검색 이탈 원인을 파악한다.
4. 호텔 검색 관련 선행 연구에서 변수, 지표, 분석 방법과 주요 결과를 비교한다.
5. 선행 연구를 근거로 지표와 가설을 설계하고 프로젝트 분석 결과를 비교·해석한다.

---

## 데이터 확보 방향

현재 분석에 어떤 데이터가 필요한지 정리하여 팀원들에게 공유했습니다. 검토 결과, 실제로 확보할 수 있는 데이터보다 가상으로 만들어야 하는 데이터가 많다는 문제가 확인되었습니다.

가상 데이터에 지나치게 의존하지 않기 위해 다음과 같은 방법으로 실제 데이터를 최대한 수집하기로 했습니다.

1. 여행사 또는 여행 플랫폼에서 공개하거나 보유하고 있는 검색 로그 데이터의 활용 가능성을 확인한다.
2. 클래스 구성원들에게 협조를 요청해 호텔 검색 및 사용자 행동 데이터를 수집한다.
3. 필요하다면 관련 커뮤니티에 설문을 게시해 표본을 확대한다.
4. 검색 목적, 여행 유형, 호텔 선택 기준 등을 조사할 수 있는 카테고리형 설문을 제작한다.
5. 수집된 실제 응답을 기반으로 부족한 데이터만 제한적으로 보완한다.

이러한 방식으로 데이터의 신뢰성을 높이고, 가상 데이터의 비중은 가능한 한 줄이는 방향으로 진행합니다.

> 여행사 검색 로그는 개인정보와 내부 데이터 문제가 있을 수 있으므로 공개 데이터 또는 사용 허가를 받은 데이터인지 확인해야 합니다.

## 설문조사 검토 사항

설문을 진행할 경우 다음 항목을 중심으로 문항을 구성할 수 있습니다.

- 여행 목적
- 여행 동반자 유형
- 검색한 지역 또는 여행지
- 호텔 검색 시 중요하게 보는 조건
- 가격대
- 숙박 기간
- 검색 및 비교 횟수
- 필터 사용 여부
- 예약 완료 또는 검색 이탈 여부
- 검색을 중단한 이유
- 최종 호텔 선택 기준

설문 문항과 응답 카테고리는 선행 연구에서 사용한 변수와 지표를 참고해 설계합니다.

---

## 호텔 검색 선행 연구 조사

소이 님이 호텔 검색과 관련된 선행 연구를 찾아 비교·정리하고 있습니다.

논문별로 다음 항목을 비교할 예정입니다.

| 비교 항목 | 확인 내용 |
| --- | --- |
| 연구 목적 | 논문에서 해결하려는 문제 |
| 분석 대상 | 호텔 검색자, 여행객 등 연구 대상 |
| 데이터 | 검색 로그, 설문, 실험 데이터 등 |
| 주요 변수 | 검색 의도, 반복 검색, 이탈 등 |
| 지표·KPI | 논문에서 정의하거나 사용한 측정 지표 |
| 분석 방법 | 통계 분석, 분류, A/B 테스트 등 |
| 주요 결과 | 프로젝트 가설에 참고할 수 있는 연구 결과 |
| 활용 가능성 | 현재 프로젝트에 적용할 수 있는 내용 |

## 논문 활용 방법

선행 연구는 단순한 참고 자료가 아니라 지표와 가설을 설계하는 근거로 활용합니다.

### 1. 지표 정의의 근거

팀의 판단만으로 지표를 정의하기보다, 기존 연구에서 사용한 지표를 참고하거나 차용합니다.

예를 들어 선행 연구에서 반복 검색, 검색 이탈 또는 전환을 특정 방식으로 정의했다면 다음과 같이 활용할 수 있습니다.

> 선행 연구에서 반복 검색을 특정 기준으로 정의하고 있으므로, 본 프로젝트에서도 해당 기준을 참고하여 반복 검색 지표를 정의한다.

### 2. 변수 및 분석 기준 참고

논문에서 사용한 변수와 분류 기준을 확인해 프로젝트의 검색 의도, 사용자 행동 유형 및 설문 카테고리를 설계합니다.

다만 논문의 지표를 그대로 사용하는 것이 아니라 다음 사항을 함께 검토해야 합니다.

- 현재 프로젝트의 목적과 일치하는가?
- 필요한 데이터를 실제로 확보할 수 있는가?
- 동일한 방식으로 계산할 수 있는가?
- 프로젝트 대상과 논문의 연구 대상이 유사한가?
- 기준을 수정한다면 그 이유를 설명할 수 있는가?

### 3. 가설 설정

선행 연구에서 확인된 결과를 바탕으로 프로젝트에서 검증할 가설을 설정합니다.

예시는 다음과 같습니다.

- 검색을 반복하는 사용자는 예약 전환까지 더 많은 시간이 걸릴 것이다.
- 검색 조건을 자주 변경하는 사용자는 검색 이탈 가능성이 높을 것이다.
- 여행 목적에 따라 호텔 선택 시 중요하게 보는 조건이 다를 것이다.

### 4. 분석 결과 비교

프로젝트 결과가 선행 연구와 일치하는지 비교하고, 결과가 다르다면 표본 규모, 데이터 수집 방식, 분석 대상의 차이 등을 통해 원인을 해석합니다.
