# 컬럼별 저장 방식 진단

현재 DB의 기존 이름 8개는 뷰다. 아래는 뷰의 87개 업무 열과 실제 저장 위치를 연결한 전수 판단표다. 모든 권고는 미적용 상태이며 사용자 확인 전 구조·코드를 변경하지 않는다.

고유값 비율은 비NULL 고유값 수 / 전체 행 수다. 빈 booking은 N/A다. “증강 대상에서 제외”는 열·원천값 삭제가 아니라 현행 사용자/세션 증강에서 새 값을 만들지 않는다는 뜻이다. 원문 ID 권고는 저장 공간보다 현재 생성기 호환성과 안전한 형식 보존을 우선한 선택이며, 일반적인 정수 대리키의 효용을 부정하지 않는다.
