# PROMPT 2.6 운영 v02 준비성 보고서

## 판정

`STEP 2.6=PASS`. 이 판정은 생성 로직·교정·테스트·실행 가드의 재승인이다. 10,000명 DB는 생성하지 않았다.

## 교정 설계

20개 seed는 config 작성 시 `[260601..260620]`으로 사전 고정했다. 각 seed에서 control-only 1,000명을 상태 전이 방식으로 생성했다. treatment는 생성하지 않았다. 각 결과 건수를 목표값에 맞춰 사후 변경하지 않았고 seed도 교체하지 않았다.

세션 잠재 탐색성→세션 길이→최초 0건→후속 검색→Markov 행동→회복→상태별 종료 순서로 생성한다. 최초 0건, 후속 0건 hazard, 즉시 회복, 최종 회복을 분리했다. Card H-SEARCH는 모든 결과 존재 검색에서 한 번 추출하며 반복 상세 이벤트 수는 별도 분포로 생성한다. `detail_event_policy=detail_only`라 click/detail 이중 집계가 없다.

## 다양성과 복제 방지

20/20 seed에서 signature, condition path, behavior path, template concentration 기준을 모두 통과했다. 완전 경로 중복은 0건이다. 경로에는 ID와 절대시간을 포함하지 않는다. 세그먼트·지역·Markov 행동·잠재성향·경계 보존 연속 jitter를 결합하며 같은 행동은 최대 2회 연속으로 제한한다. 원본 ID나 1,000명 DB 행을 사용하지 않는다.
