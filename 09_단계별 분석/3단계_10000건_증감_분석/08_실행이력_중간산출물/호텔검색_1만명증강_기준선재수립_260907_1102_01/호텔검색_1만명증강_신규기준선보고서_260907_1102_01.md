# 10,000명 증강 신규 기준선 보고서

## 판정 및 권위

`STEP 2.8=HOLD — AUTHORITATIVE_REFERENCE_NOT_UNIQUE_OR_HASH_MISMATCH`

지정 파일명은 프로젝트에서 2개 검색됐다. 두 파일 모두 46,891,008 bytes이고 SHA-256은 `9120561ee85705141a92eae74c5015fb2c9a20f0c8d1f6df4d99893952fd1e9f`이지만 “정확히 1개” 조건을 충족하지 않는다. 따라서 사용자 선택 권위 정책은 확인했으나 유일한 물리 파일의 권위 승격은 보류한다. 기존 승인 DB는 계속 `LEGACY_REFERENCE_ONLY`로 기록한다.

## 자체 무결성

SQLite `integrity_check`와 `quick_check`는 `ok`다. 외부 SQL 감사에서 8개 업무 테이블 존재, 논리 PK NULL·중복, 논리 FK orphan, SEARCH–SEARCH_FILTER 1:1, 결과 수 불일치, 검색 내 호텔 중복, EVENT 연결 불일치, 검색 순번 중복·시간 역전, 검색 전 이벤트, 세션 종료시간 위반이 모두 0건이었다. BOOKING은 0행이다.

## 신규 시간 기준

검색시간 범위는 `2027-01-01 00:01:00`부터 `2027-09-08 00:02:30`이다. 세션 내 검색 간격 5,900건은 중앙값 15초, 평균 263.122초, p90 74초, p95 109초, 최대 51,304초이며 46건(0.7797%)은 동일 timestamp다. 양수 간격 로그값 참고치는 μ=2.899725, 표본 σ=1.144826이다.

0건 후 재검색 간격은 중앙값 12초, 평균 17.745초, p95 40초다. 결과 존재 검색에서 1위 상세진입까지는 중앙값 152초지만 p90 32,168초로 긴 꼬리가 있다. click→detail은 중앙값 1초이며 1,811/5,345(33.8821%)가 동일 timestamp다. 음수 간격과 검색 순번 시간 역전은 0건이다. 긴 꼬리와 동일 timestamp는 생성 시 조건부 혼합분포로 모델링하고 exact delay를 복제하지 않는다.

## 경로 반복 분류

완전 경로는 중복 그룹 42개, 관련 세션 977개, clone excess 935건이다. 이를 기준 DB 거부 사유로 사용하지 않는다.

- `REFERENCE_OBSERVED_PATTERN`: 검색 조건 분포, 세션 길이, 순번별 0건 hazard, 후속검색·회복·Card H·이벤트 강도처럼 확률적으로 재현할 특성.
- `REFERENCE_TEMPLATE_REPETITION`: ID와 절대시간을 제외한 완전 동일 경로. 10,000명 생성 시 행·세션·지연시간과 함께 그대로 복제하지 않는다.

condition signature는 6,900건 중 226개 고유, 최빈 점유율 1.7391%, HHI 0.005995, Shannon entropy 5.263593이다. condition path는 65개 고유, 최빈 2.4%, HHI 0.022758, entropy 3.833142이다. behavior path는 43개 고유, 최빈 2.4%, HHI 0.023264, entropy 3.761025이다. 파생 template cluster는 32개, 최빈 11.7%, HHI 0.048292, entropy 3.282350이다.

## 10,000명 설계

5,000개의 동일 사전특성 pair profile을 만들고 control 5,000명과 treatment 5,000명에 한 명씩 배정한다. control은 신규 기준의 조건부 분포를 재현하되 개별 경로를 새로 생성한다. treatment는 동일 사전변수에서 교수 판단회신의 개입 이후 전이만 conservative/expected/optimistic 가정에 따라 바꾼다. 이는 실제 A/B 관측 결과가 아니라 시나리오 모의실험이다.

production schema에는 명시적 PK/FK·분석 인덱스·`sample_set_type` CHECK와 `pair_id`, `sample_stratum`, `simulation_run_id`, `random_seed`, `source_session_id`, `treatment_scenario`, `generation_model_version`를 둔다. `source_session_id`는 계보 참조일 뿐 복제 허가가 아니다.

10,000명 DB와 production mode는 실행하지 않았다. 중복 파일의 처리 주체와 보존할 정확한 절대경로가 확정되기 전 STEP 2.9는 실행할 수 없다.
