# 최종 10,000명 증강 계획서·보고서 의무 고지 템플릿

이 문서의 항목은 향후 최종 생성 계획서와 결과 보고서에서 삭제하거나 PASS 표현으로 바꾸지 않는다. 값은 실제 production SQLite 재계산값으로 채우며, 아래 대괄호만 실행 결과로 치환한다.

## A. 최종 10,000명 증강 계획서에 삽입할 내용

### 데이터 성격

본 작업은 관측형 합성 1,000명 기준 자료와 명시적 전이·효과 가정으로 control 5,000명과 treatment 5,000명을 생성하는 반복 simulation이다. 이는 실제 고객 10,000명의 추가 관측이나 실제 A/B 실험이 아니다. Treatment 효과는 conservative/base/optimistic 시나리오 가정이며 실제 인과효과로 해석하지 않는다.

### 승인된 잔여 한계

독립 expected 20-seed 평가에서 검색 0건률 평균 50.2124%와 pooled 50.2233%는 기준 95% 구간 안이었으나, 개별 seed 통과는 사전 기준 18/20보다 낮은 16/20이었다. 실패 seed 4개는 모두 상한을 초과했다. 따라서 단일 production seed에서 control 검색 0건률이 기준 범위를 벗어날 수 있는 `KNOWN_LIMITATION_SEED_INSTABILITY`가 남아 있다.

5,000명 control 환산 시 기준보다 0건 검색이 중앙 약 157건 많고, 평가 seed에 따라 약 −343~+633건 차이가 날 수 있었다. 이 수치는 합성 모형의 민감도 범위이며 실제 고객 손실이 아니다.

### 실행 전 의사결정 규칙

- Production seed는 결과 확인 전에 고정하며 유리한 seed로 교체하지 않는다.
- 검색 0건률 허용구간은 실행 결과를 본 뒤 변경하지 않는다.
- 결과가 구간 밖이면 그대로 보고하고 행 또는 KPI를 사후 보정하지 않는다.
- BOOKING은 승인 전 생성하지 않는다.
- 기준 DB와 code/config/schema의 실행 전후 SHA-256 불변성을 확인한다.
- 최종 계획서에는 기준 KPI, expected 20-seed 범위, production 판정 규칙을 함께 둔다.

## B. 최종 10,000명 결과 보고서에 삽입할 내용

### 필수 한계 고지

본 보고서의 10,000명은 합성 simulation 표본이다. 좁은 합성 표준오차는 고정된 생성모형 아래의 정밀도이며 원본의 관측 정보량이나 실제 인과 증거가 증가했음을 의미하지 않는다. Control 검색 0건률에는 독립 평가에서 확인된 seed 불안정성이 남아 있으므로 production 단일 run의 절대 KPI를 기준 모집단의 확정값으로 해석하지 않는다.

Treatment는 Z 발생 이후에 작동하므로 검색 0건률 변동이 노출 대상 수, 후속검색 분모, 즉시 회복 및 최종 회복에 전파된다. 따라서 treatment-control 차이는 `simulated scenario contrast`이며 실서비스 uplift 또는 실제 A/B 성과로 표현하지 않는다.

### 분석 결론의 허용·금지 표현

허용: “설정된 base 시나리오에서 treatment의 합성 회복률이 control보다 [값] 높게 생성됐다.”

금지: “10,000명 실제 A/B에서 개선 효과가 입증됐다”, “표본 증가로 원본 불확실성이 해소됐다”, “p-value가 작으므로 실제 정책 효과가 확정됐다.”
