## 보류된 잠금 파일

`호텔검색_1만명증강_결합전이개정및검증_260907_1418_01/tests/sequential_smoke_200.sqlite`는 실행 중인 Python 프로세스가 파일을 점유하고 있어 원래 위치에서 이동하지 못했다. 동일 크기의 사본은 목표 실행 패키지 아래에 생성되었으며, 원본 잠금 파일은 삭제하지 않았다. 점유 프로세스가 종료된 뒤 사본과 원본의 SHA-256을 비교하고 원본을 제거하거나 이동해야 정리가 완전히 종결된다.

## 재현성 주의

이동 전 절대경로를 문자열로 기록한 과거 manifest·로그·스크립트는 예전 위치를 계속 가리킬 수 있다. 과거 실행 증거로는 그대로 보존하되, 재실행 시에는 이 문서의 새 경로와 `stage3_reorganization_plan_*.csv`를 이용해 입력 경로를 명시적으로 갱신해야 한다.
