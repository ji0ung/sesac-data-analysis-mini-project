# 일본 호텔 검색 행동 분석 프로젝트

호텔 검색 과정에서 발생하는 결과 없음, 재검색, 조건 변경과 상세 진입 행동을 분석하는 2팀 프로젝트 저장소다. 문서와 일반 산출물은 한글 폴더명으로 관리하고, 재현성이 필요한 단계별 분석 실행묶음은 기존 구조를 유지한다.

## 주요 경로

| 경로 | 내용 |
|---|---|
| `00_프로젝트관리/` | 관리 규칙, 버전관리대장, 회의록 |
| `01_프로젝트기획/` | 팀 프로젝트 및 개인 기획 산출물 |
| `02_자료조사/` | 논문, 서비스 비교, 참고자료 |
| `03_데이터모델링/` | 현행 데이터, 명세, 품질 기준, 이전 스냅샷 |
| `04_분석설계/` | 가설, 분석 설계, 분석 결과 |
| `05_발표자료/` | 팀·개인 발표자료 |
| `06_가이드와프롬프트/` | 작업 가이드와 재사용 프롬프트 |
| `07_교육과제/` | 팀 과제, 개인 과제, 강의 제공자료 |
| `08_보관자료/` | 사용이 종료된 장기 보관자료 |
| `09_단계별 분석/` | 재현 가능한 단계별 분석 실행묶음 |
| `10_웹앱/호텔검색행동실험/` | 호텔 검색 행동 실험 웹앱 |
| `공통스크립트/` | 문서 및 분석 산출물 생성 보조 코드 |

## 분석 기준

- 현재 기준 데이터: `03_데이터모델링/현행데이터/`의 `2026-09-03_v03` 비식별 데이터
- 데이터 품질 규칙: `03_데이터모델링/데이터품질/`
- 단계별 실행 자료: `09_단계별 분석/`
- 문서 기준본: `00_프로젝트관리/버전관리대장/문서_버전관리대장.md`

## 관리 원칙

1. 일반 산출물은 팀·개인·제공자료를 구분하고 생성 연도와 월로 정리한다.
2. 구분이 불명확한 기존 파일은 임의로 이동하지 않는다.
3. 문서 계열별 현행본은 하나만 두고 이전 버전은 `이전버전/`에 보관한다.
4. `09_단계별 분석/`의 실행묶음은 내부 파일을 분리하거나 이름을 임의로 바꾸지 않는다.
5. 개인정보 확인 전 파일과 로컬 작업 산출물은 Git에 추가하지 않는다.

상세 기준은 `00_프로젝트관리/관리규칙/문서_폴더관리규칙.md`에서 확인한다.
