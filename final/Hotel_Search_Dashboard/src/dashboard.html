지표의 역할·해석 기준

주 KPI는 문서 기준 후속 검색의 즉시 회복률입니다. 모든 0건 검색을 분모로 한 회복률도 함께 보아, 후속 검색을 하지 않은 경우가 빠지는 영향을 확인합니다. 마지막 검색 회복률과 회복 후 클릭률은 보조 지표이며 실험의 보호지표와 허용 악화 기준은 별도 확정 자료가 필요합니다.

후속 검색률은 사용자 참여 상황을 보는 진단 지표입니다. 무조건 높이는 목표로 두지 않습니다. 검색량이 늘어도 결과를 찾지 못하면 개선이라고 볼 수 없습니다.

검색결과 4개 · 세션 단위

첫 검색의 결과 유무를 먼저 나눈 뒤, 첫 결과가 있으면 세션 내 호텔 클릭 유무, 첫 결과가 없으면 후속 검색의 결과 회복 유무로 분류합니다.

중복 없음: 검색이 있는 세션마다 정확히 1개 성과군. 전체 기준 630 + 231 + 92 + 47 = 1,000세션입니다.

판정 시점·예외·필터 적용

세션 안에서 search_time → search_id 오름차순으로 정렬합니다. 같은 사용자가 여러 세션을 가지면 성과군은 세션마다 달라질 수 있습니다. 한 세션의 전체 검색 기록으로 판정한 후, 세션 시작 월과 성과군으로 필터링합니다.

첫 검색 결과가 있으면 이후 0건 검색을 했더라도 SG1 또는 SG2입니다. 첫 검색이 0건이면 클릭 여부와 관계없이 후속 검색에서 한 번이라도 결과를 찾으면 SG3입니다. 후속 검색이 아예 없어도 SG4이며, 이를 이탈이나 구매 실패로 단정하지 않습니다.

의도군과 성과군은 서로 다른 축입니다. 성과군은 행동 후 판정하므로 대조군·실험군 또는 실험 전 의도군으로 사용하지 않습니다. 기본 퍼널에는 기간만 적용하고 성과군은 별도 비교에 적용합니다.

발표 대본 · 02 · 가설별 검증

기본 수치는 전체 데이터 기준입니다. 필터를 바꿨다면 화면의 수치를 사용하세요.

가설별로 대상과 지표, 관측 근거를 연결했습니다. H1은 전체 회복, H2는 의도별 차이, H3은 상세진입, H4는 반복 방지, H5는 지역 확대, H6은 검색어 제안입니다. H0는 비교 지표에 차이가 없다는 출발 가설입니다.

현재 그래프는 확장본의 행동별 관측 근거입니다. 전체 데이터에서 지역 변경의 회복률은 41.4%, 조건 완화는 26.7%입니다. 지역 변경은 조건 완화보다 14.7퍼센트포인트 높고 상대 변화율은 약 55.0%입니다. 14.7%p와 55.0%는 다른 표현이며, 이는 무작위 배정된 제안 효과가 아닙니다.

분모가 0이면 비율을, 기준군 비율이 0이면 상대 변화를 계산하지 않습니다. p값과 신뢰구간은 미산출입니다. 유의하지 않다는 판정도, 유의하다는 판정도 붙이지 않았습니다.
