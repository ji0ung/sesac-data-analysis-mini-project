# 호텔 검색 분석 발표 대본

HTML의 00~04 페이지에 대응합니다. 모든 기본 수치는 전체 필터 기준입니다.

최종본은 총 34장입니다. 1~5장은 주제·팀원·의도·논문 자료 대기·설문, 6~8장은 StayTrace 참여 화면·콘솔 현황·옵션 일치/불일치 실험, 9장은 가설입니다. 10~12장은 배경·용어·출처, 13~15장은 시행착오·증강·한계, 16~18장은 10,000명 시뮬레이션 한계, 19장은 용량 줄이기입니다. 20~21장은 KPI, 22~23장은 현황·퍼널, 24장은 방법별 비교, 25장은 분류 기준, 26~27장은 세그먼트, 28~31장은 여정도, 32장은 추세, 33장은 A/B 연결, 34장은 결론입니다.

각 슬라이드의 대본은 기본 닫힘입니다. StayTrace의 170명·176세션·608검색은 2026-09-07 16:04:24 제공 스크린샷의 누적 현황입니다. 현재 정제 원본과 1,000명 확장본, 10,000명 시뮬레이션의 수치와 섞지 않습니다. 옵션 일치/불일치 실험의 36/20세션은 별도의 부분 집계이고, 현재 회복 개선안 A/B의 결과가 아닙니다.

## 00 · 주제와 전체 요약

오늘 발표할 주제는 호텔 검색에서 결과가 없을 때 사용자가 어떻게 다시 검색하고 결과를 찾는지입니다. 원본 296건 중 147건, 약 절반에서 결과가 없었습니다. 그 뒤 140건은 다음 검색으로 이어졌지만 즉시 회복은 24건에 그쳤습니다. 재검색 자체보다 다시 결과를 찾도록 돕는 방법에 주목한 이유입니다.

분석은 수집한 로그를 정제한 41명·43세션·296검색에서 출발했습니다. 원본 세션을 재표집·복제하고 식별자와 시간축을 재구성해 1,000명·1,000세션·6,900검색으로 확장했습니다. 새로 관측한 1,000명은 아니며, 합성 표본으로 실제 효과가 검증되었다고 말하지 않습니다.

검색의도는 제안 전에 무엇을 바꿀 수 있는지를, 성과 세그먼트는 검색 후 어떤 결과에 도달했는지를 구분합니다. 이 두 기준을 연결해 개선안의 비교 지표를 정리했습니다.

## 01 · 전체 현황·검증 과제

지금부터는 확장본의 관측 집계를 보겠습니다. 전체 필터 기준 결과 없음은 3,434/6,900, 49.8%입니다. 전체 검색의 결과 분포와 0건 이후 회복 퍼널을 분리했습니다.

0건 검색 3,434건 중 3,271건에 후속 검색이 있고, 558건이 즉시 회복했습니다. 회복한 검색 중 클릭 기록이 있는 것은 326건입니다. 즉시 회복률 17.1%의 분모는 후속 검색 3,271건입니다. 모든 0건 검색이 분모일 때는 16.2%입니다. 후속 검색 기록이 없는 163건을 서비스 이탈로 단정하지 않습니다.

기본 회복 퍼널에는 기간만 적용합니다. 성과군을 선택해도 기본 퍼널은 유지되며, 선택한 집단은 별도 비교 영역에 표시합니다. 직접 성공·재검색 회복 집단에서 관측되는 100%는 이 비교 영역의 값입니다. 다른 KPI와 그래프에는 기간과 성과군을 모두 적용하므로 필터 범위와 분모를 함께 읽어주세요.

이 대본의 수치는 전체 필터 기준입니다. 월이나 성과군을 바꿨다면 화면에 표시된 수치로 설명합니다.

### 추가 설명

출처: 원본 v03 비식별 SQLite · 관측형 합성1000명 생성 코드(260903_1606_01) · 현재 44.72MiB DB. 원본과 확장본은 별도 보관하며, 아래 필터와 그래프는 현재 확장본에 적용됩니다.

사용자 수가 아닌 검색·연결 전환 건수입니다. 한 세션의 여러 0건 검색이 각각 포함됩니다. ‘후속 검색 기록 없음’은 세션 안에 다음 검색이 없다는 뜻이며, 서비스 이탈을 확정한 값은 아닙니다. 마지막 단계는 회복한 검색의 hotel_click 존재 기준입니다.

의도군 기준은 문서의 개념 정의입니다. 실제 배정 규칙·중복 시 우선순위·의도군별 인원은 기존 세그먼트 매핑 자료에서 확인해야 합니다. 현재 경량 DB만으로 의도를 역추정하거나 인원을 배분하지 않았습니다.

클릭은 세션 내 hotel_click 1회 이상을 뜻합니다. ‘직접 성공’은 첫 검색에 결과가 있고 세션 중 클릭한 경우이며, 첫 검색에서 바로 클릭했거나 예약했다는 뜻은 아닙니다. ‘재검색 회복’은 후속 검색 중 한 번이라도 결과가 나온 경우로, 마지막 검색 회복 지표와는 기준이 다릅니다.

여러 방법에 같은 세션이 포함될 수 있습니다. 관측된 행동별 비교이며 제안의 인과효과를 뜻하지 않습니다.

선택한 세션을 4개 결과군으로 구분했습니다. 첫 검색 결과와 세션 내 클릭·후속 회복 기준입니다.

DB 시간축: 2027-01-01~2027-09-08. 실제 운영 추이·계절성으로 해석하지 않습니다. 9월은 일부 기간만 포함됩니다.

## 02 · 가설별 검증

가설별로 대상과 지표, 관측 근거를 연결했습니다. H1은 전체 회복, H2는 의도별 차이, H3은 상세진입, H4는 반복 방지, H5는 지역 확대, H6은 검색어 제안입니다. H0는 비교 지표에 차이가 없다는 출발 가설입니다.

현재 그래프는 확장본의 행동별 관측 근거입니다. 전체 데이터에서 지역 변경의 회복률은 41.4%, 조건 완화는 26.7%입니다. 지역 변경은 조건 완화보다 14.7퍼센트포인트 높고 상대 변화율은 약 55.0%입니다. 14.7%p와 55.0%는 다른 표현이며, 이는 무작위 배정된 제안 효과가 아닙니다.

분모가 0이면 비율을, 기준군 비율이 0이면 상대 변화를 계산하지 않습니다. p값과 신뢰구간은 미산출입니다. 유의하지 않다는 판정도, 유의하다는 판정도 붙이지 않았습니다.

## 03 · A/B 테스트

기존에 만든 세그먼트 A/B와 연결할 영역입니다. 44.72MiB 파일에서 실험 배정 이벤트 6,096건은 확인되지만, 배정 그룹이나 variant, 의도군 매핑은 포함되어 있지 않습니다. 이벤트 개수를 배정 사용자 수로 해석하지 않습니다.

현재 가능한 비교는 결과 세그먼트와 0건 경험 여부에 따른 관측 비교입니다. 의도군별 개선안으로는 가격·옵션 조건 완화, 지역 확대, 반복 안내, 검색어 제안, 단계 안내가 있습니다.

실제 A/B 결과를 제시할 때는 집단 정의, 무작위 배정 단위, 주지표와 보호지표, 표본과 기간, 분자·분모 및 기존 판정을 연결해야 합니다. 이 화면의 미연결 표시는 A/B가 만들어지지 않았다는 뜻이 아닙니다.

### 추가 설명

결과군은 행동 후 분류입니다. 이를 무작위 대조군·실험군으로 바꾸어 부르지 않습니다.

세션 중 hotel_click이 1회 이상 발생한 비율. 0건 경험 여부와 클릭의 관련성을 보여주며, 배정 효과는 아닙니다.

## 04 · 핵심 발견·의사결정

발견은 세 가지입니다. 첫째, 재검색은 많이 하지만 바로 결과를 찾는 비율은 낮습니다. 둘째, 지역 변경·조건 완화 등 행동에 따라 회복률 차이가 관측됩니다. 셋째, 동일 조건 반복에서는 회복이 관측되지 않았습니다.

이 결과는 어떤 개선안을 검토할지 알려주는 관측 근거입니다. 합성 확장본의 차이를 실제 제안의 인과효과로 단정하지 않습니다. 채택·추가 실험·중단 판단은 기존 A/B의 효과, 불확실성, 보호지표와 연결해야 합니다.

현재 완료한 것은 관측 집계와 비교 화면입니다. A/B 판정이 아직 연결되지 않은 항목은 그대로 구분해 제시합니다.

## KPI 공식·목표 계산 설명

주 KPI는 0건 이후 후속 검색에서 결과를 찾은 비율입니다. 현재 확장본에서 558/3,271 = 약 17.1%입니다. 모든 0건 검색을 분모로 하면 558/3,434 = 16.2%이므로 두 지표의 분모를 구분합니다. 후속 검색률은 진단 지표로, 재검색만 많아지는 것을 개선으로 보지 않습니다.

목표 회복률을 입력하면 후속 검색 3,271건을 고정해 목표 건수를 올림 계산합니다. 예를 들어 20%를 입력하면 최소 655건의 회복이 필요하며, 현재 558건보다 97건이 더 필요합니다. 이는 설명용 입력 예시이며 확정 목표가 아닙니다. 목표 차이는 약 +2.9%p, 상대 개선율은 약 +17.2%입니다.

이 계산은 효과 예측이나 통계적 실험 표본 수 계산이 아닙니다. 00 페이지의 목표 기준선은 전체 확장본에 고정되어 월·성과군 필터를 바꿔도 유지됩니다.

## 세그먼트 기준 설명 대본

의도는 어떤 대안을 받아들일 수 있는지, 성과는 세션에서 실제로 무엇이 일어났는지를 구분합니다. 성과는 첫 검색 결과로 먼저 나누고, 결과가 있으면 클릭 여부, 없으면 이후 회복 여부로 네 그룹 중 하나에 넣습니다. 직접 성공은 세션 내 클릭이며 예약 성공이 아닙니다. 의도군은 기존 문서의 사용자당 잠재 의도 한 개라는 정의를 가져왔지만, 현재 집계에는 배정값이 없어 인원이나 효과를 제시하지 않습니다. 자세한 기준과 근거는 Segment_Definitions.md를 참고합니다.

## 세그먼트별 여정 설명

성과군 여정은 첫 검색 결과 → 이후 회복 또는 세션 내 클릭 여부라는 분류 순서를 시각화한 것입니다. 모든 클릭이 회복 후에 발생했다고 보장하는 이벤트 순서도는 아닙니다. 전체 기준 직접 성공 630세션, 결과 노출·미선택 231세션, 재검색 회복 92세션, 지속 실패 47세션입니다. 회복군 중 세션 내 클릭은 69/92 = 75.0%이며, 회복 직후 클릭률과 구분합니다. 지속 실패의 재검색 없음과 재검색 후 미회복은 현재 집계에서 세션 수가 분리되지 않아 합쳐 표시했습니다.

의도별 여정은 사용자의 성향에 맞춰 어떤 대안을 제시할지 설명하는 문서 기반 흐름입니다. 실제 의도별 행동 경로·노출률·실험 결과가 아니며, 미수용과 미회복도 가능합니다. 실제 배정값을 연결한 뒤 제안 수용·회복·클릭을 측정해야 합니다.
