## 1. 결론

통제모형에서 편의시설 3개 이상 설정은 다른 제한조건·도시·체크인월·투숙객 수·숙박일수를 통제한 뒤에도 0건 검색과 가장 큰 양의 연관을 보였다. 다만 이는 관찰형 합성 데이터의 연관이며, 편의시설 조건을 해제하면 결과가 인과적으로 개선된다는 뜻은 아니다. A-1 파일럿에서는 세 선택지를 동등 노출하되 편의시설 일부 해제를 우선 관찰 대상으로 두는 것이 적절하다.

## 3. 전처리 및 계산 계약

1. `search`와 `search_filter`를 `search_id`로 1:1 내부 결합했다.
2. 검색 순서는 `session_id`, 파싱된 `search_time`, `search_id`의 안정 정렬로 확정했다.
3. 0건 후 전이는 `total_result_count=0`인 검색과 같은 세션의 바로 다음 검색 한 건으로 정의했다.
4. 상세진입은 중복 행동지표를 합산하지 않고 `hotel_click`이 존재하는 검색으로 정의했다.
5. 순위별 클릭률은 반복 클릭을 제거한 고유 `(search_id, hotel_id)` 클릭 결과를 분자로 사용했다.
6. 원형 세션 지문은 검색·필터 상태 시퀀스로 생성했다. 생성 과정에서 역전된 숙박일이 임의의 유효 기간으로 교정됐으므로 체크인·체크아웃 날짜는 지문에서 제외했다.
7. 통제모형은 복원된 43개 원형 세션의 대표 검색 296건을 사용한 이항 GLM이다. 표준오차는 대표 세션 43개를 군집으로 계산했다.

통제모형 식:

```text
0건 여부 ~ 가격 설정 + 최소 평점 설정 + 편의시설 3개 이상
          + 도시 + 체크인월 + 투숙객 수 + 숙박일수
```

## 5. 인사이트 카드 재계산

### 카드 A — 제한 조건과 결과 없음

| 제한 조건 | 0건 검색/조건 설정 검색 | 0건률 |
|---|---:|---:|
| 편의시설 3개 이상 | 2,808/3,181 | 88.3% |
| 최소 평점 설정 | 2,695/3,558 | 75.7% |
| 가격 설정 | 2,473/3,408 | 72.6% |

계산 경로: `search.total_result_count` → 0건 여부 생성 → `search_filter` 조건 플래그와 1:1 결합 → 조건별 0건 검색 수/조건 설정 검색 수.

수치 해석: 편의시설 3개 이상 검색의 0건률은 88.3%로 가격 설정 검색 72.6%보다 15.7%p 높다. 조건들이 함께 설정될 수 있으므로 단순 비율만으로 독립효과를 확정하지 않는다.

### 카드 B — 0건 후 재검색과 이탈 측정 공백

- 0건 후 후속검색: **3,271/3,434 = 95.3%**
- 세션 시작 이벤트: 1,000건
- 세션 종료 이벤트: 23건

계산 경로: 0건 검색 3,434건 → 동일 세션의 바로 다음 검색 존재 여부 → 후속검색 3,271건.

수치 해석: 후속검색은 95.3%로 관측됐지만, 종료 이벤트 완전성이 23/1,000에 불과하다. 후속검색이 없는 163건을 즉시 이탈로 확정할 수 없으므로 B-1 로깅 명세가 선행돼야 한다.

### 카드 C — 즉시 회복과 세션 최종 회복

| 지표 | 분자/분모 | 결과 |
|---|---:|---:|
| 즉시 회복률 | 558/3,271 전이 | 17.1% |
| 세션 최종 회복률 | 488/651 세션 | 75.0% |

즉시 회복의 분모는 0건 뒤 바로 다음 검색이 존재하는 전이이고, 세션 최종 회복의 분모는 0건을 한 번 이상 경험한 세션이다. 두 지표의 분모와 단위가 다르므로 17.1%에서 75.0%로 상승했다고 해석하지 않는다.

### 카드 D·F — 재검색 방법별 결과

| 재검색 방법 | 전이 수 | 결과 회복 | 상세진입 |
|---|---:|---:|---:|
| 지역 변경 | 563 | 233/563 = 41.4% | 70/563 = 12.4% |
| 검색어 변경 | 234 | 69/234 = 29.5% | 69/234 = 29.5% |
| 조건 완화 | 959 | 256/959 = 26.7% | 187/959 = 19.5% |
| 동일조건 반복 | 1,238 | 0/1,238 = 0.0% | 0/1,238 = 0.0% |
| 조건 강화 | 231 | 0/231 = 0.0% | 0/231 = 0.0% |
| 완화·강화 혼합 | 46 | 0/46 = 0.0% | 0/46 = 0.0% |

수치 해석: 지역 변경의 회복률 41.4%는 조건 완화 26.7%보다 14.7%p 높지만, 상세진입률은 검색어 변경이 29.5%로 지역 변경 12.4%보다 17.1%p 높다. 회복과 상세진입의 우선 방법이 다르므로 단일 우승 방법으로 해석하지 않는다.

### 카드 G — 상호작용 성공 유형

| 세션 유형 | 세션 수/전체 | 비율 |
|---|---:|---:|
| 직접 상호작용 성공 | 69/1,000 | 6.9% |

세 유형은 상호배타적이며 합계는 1,000개다. 상호작용은 승인된 단일 지표인 `hotel_click`으로 판정했다. 종료 로그가 부족하므로 상호작용 없음 301개를 실제 이탈로 해석하지 않는다.

### 카드 H — 순위별 고유 클릭

| 순위 | 고유 클릭 결과/노출 결과 | 고유 클릭률 |
|---|---:|---:|
| 1위 | 680/3,466 | 19.6% |

| 3위 | 139/2,717 | 5.1% |
| 4위 | 69/2,576 | 2.7% |

수치 해석: 1위의 고유 클릭률은 19.6%로 2위 8.0%보다 11.6%p 높다. 그러나 5위 3.7%가 4위 2.7%보다 1.0%p 높아 순위가 낮아질수록 일관되게 감소하지 않는다. 가격·평점·호텔 특성을 통제한 검증 전에는 순위 자체의 인과효과로 해석하지 않는다.

## 6. A-2 통제 분석

| 조건 | 조정 오즈비 | 95% 신뢰구간 | p값 | 조건 미설정 표준화 0건 확률 | 조건 설정 표준화 0건 확률 | 차이 |
|---|---:|---:|---:|---:|---:|---:|
| 편의시설 3개 이상 | 29.69 | 8.88~99.33 | <0.001 | 21.2% | 82.3% | +61.1%p |
| 가격 설정 | 2.26 | 0.38~13.46 | 0.372 | 45.0% | 55.2% | +10.2%p |
| 최소 평점 설정 | 1.38 | 0.33~5.72 | 0.658 | 47.8% | 51.5% | +3.8%p |

모형 모집단은 증강 1,000세션 전체가 아니라 복원한 원형 세션 43개, 검색 296건이다. 표준화 확률은 각 제한조건만 0 또는 1로 바꾸고 나머지 관측 공변량을 유지한 모형 예측치의 평균이다.

수치 해석: 편의시설 3개 이상 조건의 조정 오즈비는 29.69이고 표준화 0건 확률 차이는 +61.1%p로 세 조건 중 가장 크다. 가격과 평점의 신뢰구간은 1을 포함해 불확실성이 크다. 따라서 A-1 파일럿에서 편의시설 일부 해제를 중점 관찰하되, 관찰형 합성 데이터이므로 동등 노출 실험 전에는 인과효과로 확정하지 않는다.

## 8. 한계와 사용 원칙

- 증강 1,000세션은 43개 원형 경로의 복제이므로 독립 표본 수가 1,000개로 증가한 것이 아니다.
