## 1. 결론

결과 없음은 편의시설·최소 평점·가격 조건을 적용한 검색에서 집중적으로 관찰됐다. 결과가 없더라도 후속 검색은 자주 이어졌지만, 바로 다음 검색에서 결과가 회복된 비율은 낮았다. 특히 동일 조건 반복과 조건 강화에서는 회복이 관찰되지 않았다. 따라서 결과 없음 화면은 종료 화면보다 `지역 변경`, `검색어 변경`, `조건 완화`를 돕는 재탐색 화면으로 설계할 필요가 있다.

다만 이 데이터는 실험 참여자의 짧은 기간 행동이고 세션 종료 이벤트도 거의 수집되지 않았다. 아래 결과는 관찰적 연관성이며 기능의 인과효과를 증명하지 않는다.

## 4. 지표 계약과 전처리

| 지표 | 분석 단위 | 계산 계약 |
|---|---|---|
| 조건별 결과 없음률 | 검색 | 조건을 만족하면서 `total_result_count=0`인 검색 / 해당 조건 검색 |
| 후속 검색률 | 검색 | 같은 세션에 더 늦은 검색이 있는 검색 / 해당 결과 상태 검색 |
| 즉시 회복률 | 전환 | 결과 없음 직후 검색의 `total_result_count>0` / 결과 없음→다음 검색 전환 |
| 세션 최종 회복률 | 세션 | 마지막 검색 결과가 1건 이상인 세션 / 결과 없음을 한 번 이상 경험한 세션 |
| 방법별 상세진입률 | 전환 | 후속 검색에 `hotel_detail_view`가 존재하는 전환 / 방법별 전환 |
| 고유 노출-클릭 전환율 | 검색 결과 | 한 번 이상 유효 클릭된 `(search_id, hotel_id)` / 해당 순위 검색 결과 |
| 노출당 클릭 이벤트 수 | 검색 결과 | 유효 `hotel_click` 이벤트 수 / 해당 순위 검색 결과 |

추가 처리 규칙은 다음과 같다.

1. 검색 순서는 `session_id`, `search_time`, `search_id` 순으로 정렬했다.
2. 다음 검색은 동일 세션에서 바로 뒤에 있는 검색으로 정의했다.
3. 결측 필터는 미설정 상태로 유지했고 대체값을 넣지 않았다.
4. 검색, 필터, 검색 결과와 이벤트 원본 행은 제거하거나 중복 제거하지 않았다.
5. 전환 유형만 상호배타적으로 분류했다. 우선순위는 `동일 조건 → 지역 변경 → 검색어 변경 → 조건 완화/강화`다.
6. 가격 상향·해제, 최소 평점 하향·해제, 편의시설 수 감소는 완화로 정의했다. 반대 방향은 강화다.
7. 완화와 강화가 동시에 존재한 2건은 `완화·강화 혼합`으로 분리했다.

## 5. 상세 분석

### 5.1 제한 조건과 결과 없음

| 조건 | 조건 적용 | 비교 집단 | 차이 | 위험비 |
|---|---:|---:|---:|---:|
| 편의시설 3개 이상 | 120/136 = 88.2% | 3개 미만 27/160 = 16.9% | +71.4%p | 5.23배 |
| 최소 평점 설정 | 115/152 = 75.7% | 미설정 32/144 = 22.2% | +53.4%p | 3.40배 |
| 가격 조건 설정 | 106/146 = 72.6% | 미설정 41/150 = 27.3% | +45.3%p | 2.66배 |

관찰값만 보면 편의시설 조건의 차이가 가장 크다. 그러나 가격·평점·편의시설은 함께 설정될 수 있으므로 위험비를 각 조건의 독립적인 인과효과로 해석할 수 없다.

의사결정 제안은 결과 없음 화면에 편의시설 해제, 평점 하향, 가격 범위 확대를 바로 제공하는 것이다. 실제 우선순위는 조건 간 중복을 통제한 모델 또는 무작위 실험으로 검증해야 한다.

### 5.2 결과 없음 이후 후속 검색

| 검색 결과 | 후속 검색 있음 | 후속 검색률 |
|---|---:|---:|
| 결과 없음 | 140/147 | 95.2% |
| 결과 있음 | 113/149 | 75.8% |

두 비율의 차이는 +19.4%p이며, 후속 검색 오즈비는 6.37이다. Fisher의 정확 검정 결과는 `p=0.00000181`로 관찰된 차이가 우연만으로 나타났다는 설명과는 잘 맞지 않는다.

그러나 결과 없음이 재검색을 유발했다고 단정할 수 없다. 결과 없음 경험 세션은 평균 검색 횟수가 9.00회로 비경험 세션의 2.93회보다 많았고, 탐색 의지가 높은 사용자가 결과 없음도 더 자주 경험했을 수 있다.

### 5.3 즉시 회복과 세션 최종 회복

| 지표 | 분자/분모 | 결과 |
|---|---:|---:|
| 즉시 회복 | 24/140 전환 | 17.1% |
| 세션 최종 회복 | 21/28 세션 | 75.0% |

17.1%는 결과 없음 바로 다음 검색의 전환 단위 지표이고, 75.0%는 결과 없음 경험 세션의 마지막 검색을 보는 세션 단위 지표다. 따라서 `17.1%에서 75.0%로 상승했다`거나 `+57.9%p 개선됐다`고 표현하지 않는다.

운영 KPI도 첫 재검색 회복률과 세션 최종 회복률을 분리해야 한다. 첫 시도가 실패한 사용자에게 두 번째 대안까지 제시할 필요가 있다는 정도로 해석할 수 있다.

### 5.4 재검색 방법별 차이

| 재검색 방법 | 전환 수 | 결과 회복 | 상세진입 |
|---|---:|---:|---:|
| 동일 조건 | 53 | 0/53 = 0.0% | 0/53 = 0.0% |
| 지역 변경 | 24 | 10/24 = 41.7% | 3/24 = 12.5% |
| 검색어 변경 | 10 | 3/10 = 30.0% | 3/10 = 30.0% |
| 조건 완화 | 41 | 11/41 = 26.8% | 8/41 = 19.5% |
| 조건 강화 | 10 | 0/10 = 0.0% | 0/10 = 0.0% |
| 완화·강화 혼합 | 2 | 0/2 = 0.0% | 0/2 = 0.0% |
| 합계 | 140 | 24/140 = 17.1% | 14/140 = 10.0% |

지역 변경의 회복률이 41.7%로 가장 높고, 검색어 변경의 상세진입률이 30.0%로 가장 높았다. 다만 검색어 변경은 10건, 조건 강화는 10건, 혼합은 2건뿐이므로 우열을 확정하기 어렵다.

원문 근거의 `검색어 수정 11/41=26.8%`는 분자·분모가 조건 완화와 중복되어 있다. 상호배타 분류로 재계산하면 검색어 변경 회복은 `3/10=30.0%`, 조건 완화 회복은 `11/41=26.8%`다.

### 5.5 탐색 지속성

| 집단 | 세션 | 평균 검색 | 중앙값 |
|---|---:|---:|---:|
| 결과 없음 경험 | 28 | 9.00회 | 7회 |
| 결과 없음 비경험 | 15 | 2.93회 | 2회 |

Mann–Whitney 검정은 `U=382`, `p=0.0000112`다. 집단의 검색 횟수 분포가 다르다는 관찰은 지지하지만, 결과 없음이 탐색 지속성을 높였다는 인과결론은 지지하지 않는다. 사용자의 원래 탐색 의도가 공통 원인일 수 있다.

문서의 순위별 수치는 유효 클릭 이벤트를 모두 세어 분자에 넣으면 정확히 재현된다. 하지만 유효 클릭 229건은 고유 `(search_id, hotel_id)` 66개에서 발생했으며, 같은 결과에 대한 반복 클릭 163건이 포함되어 있다. 따라서 73.8% 등을 `상세진입 전환율`로 부르면 한 결과의 반복 행동이 전환을 여러 번 만든 것처럼 계산된다.

전환율이 목적이라면 고유 결과 기준인 1위 19.5%, 2위 8.0%, 3위 5.1%, 4위 2.7%, 5위 3.7%를 사용한다. 반복 클릭 강도가 목적이라면 기존 수치를 유지하되 지표명을 `노출당 클릭 이벤트 수`로 바꾼다. 두 정의 모두 5위가 4위보다 높아 단조 감소하지 않으므로 순위 자체의 인과효과를 확정할 수 없다.

## 6. 권고안

1. 결과 없음 화면에서 `지역 변경`, `검색어 변경`, `가격·평점·편의시설 완화`를 동시에 제공한다.
2. 동일 조건 재제출을 감지하면 같은 요청을 반복 실행하기보다 변경 가능한 조건을 표시한다.
3. 조건을 더 강화할 때 결과 수가 줄어들 수 있음을 사전에 안내한다.
4. 재검색 지원 성과는 `첫 재검색 회복률`, `세션 최종 회복률`, `후속 상세진입률`로 분리한다.
5. 순위별 전환율은 클릭 이벤트 수가 아니라 고유 `(search_id, hotel_id)` 단위로 집계한다.
6. 지역 변경·검색어 변경·조건 완화별 표본을 최소 30건 이상 확보한 A/B 테스트로 제시 순서를 검증한다.
7. `page_exit`, `session_end`, 세션 타임아웃 이벤트를 보강해 실제 이탈률을 측정한다.

## 7. 한계와 반증 조건

- 검색 기록은 4일간의 실험 참여자 행동이며 자연 유입 사용자를 대표하지 않을 수 있다.
- 검색 세션은 43개, 사용자 연결은 41명으로 사용자 반복 관측이 존재한다.
- `session_start` 89건에 비해 `session_end`는 2건뿐이어서 즉시 이탈 0건을 실제 무이탈로 해석할 수 없다.
- 재검색 방법은 우선순위를 사용해 상호배타적으로 분류했으며 다른 분류 계약에서는 비율이 달라질 수 있다.
- 검색어 변경과 조건 강화는 각각 10건, 혼합 유형은 2건으로 불확실성이 크다.
- 가격·평점·편의시설 설정은 서로 중복되므로 단변량 결과 없음률은 독립효과가 아니다.
- 동일 호텔의 순위를 무작위로 바꾼 실험에서 상위 순위 우세가 사라지면 순위 효과 해석은 기각해야 한다.
- 자연 유입에서 이탈 이벤트를 수집했을 때 결과 없음 후속 검색률 차이가 사라지면 재검색 지원 근거를 재검토해야 한다.
