# 호텔검색 10,000명 ERD 보존 경량 DB 읽기 전용 진단

- 수정일: 2026-09-08
- 문서 상태: 현행본
- 진단 대상: `호텔검색_1만명증강_탐색용AB10000_260907_1544_01_ERD보존_정수키_16K.sqlite`
- 비교 대상: `호텔검색_1만명증강_탐색용AB10000_260907_1544_01.sqlite`
- 진단 원칙: 두 DB와 생성 코드를 수정하거나 덮어쓰지 않음

## 핵심 판정

1. 현재 경량본에는 사전 매핑 테이블이 없다. 문자열 ID가 INTEGER로 치환됐지만 원래 문자열 ID를 복원할 데이터는 저장되지 않았다.
2. 두 DB 모두 실제 테이블 12개이며 테이블명과 컬럼명·순서는 같다. 경량본의 PK·FK ID 자료형만 INTEGER로 변경됐다.
3. `integrity_check=ok`, `foreign_key_check` 위반 0건, 행 수 일치로 현재 DB 내부 관계는 정상이다.
4. 실행 매니페스트에 기록된 최종 생성기 `호텔검색_1만명증강_generator_sequential_v06_260907_1418_03.py`와 선행 생성기 `05_generator_newref_v02.py`가 저장소에 존재한다. 생성기는 규칙형 문자열 ID를 생성했고 경량화는 생성 이후 별도 단계에서 수행됐다.
5. 원본 ID는 UUID나 128비트 16진수 값이 아니라 `U00001C`, `S00001C`, `Q00001C01`과 같은 규칙형 문자열이다. 경량화 스크립트는 문자열을 정수로 직접 변환하지 않고 ID 영역별 정렬 순서에 따라 연속 정수키를 부여했다. 따라서 UUID 정수 변환에 따른 자릿수 손실은 없다.
6. 현재 파일은 이미 10,000명 결과다. 경량본은 분석·조회용이며, 추가 증강은 경량본을 입력으로 이어 붙이기보다 기준 DB와 생성기에서 다시 실행하는 것이 재현성과 ID 충돌 방지에 적합하다.

## 저장 구조 식별

- 원문 문자열 저장: 업무 범주, 검색어, 지역, 시간, 실행 설명, 기준 세션 계보.
- 정수 ID 저장: 모든 내부 PK·FK와 `pair_id`.
- 사전 매핑 테이블: 없음. `_generation_metadata`는 실행 메타데이터이며 ID 사전이 아니다.
- 원래 ID 문자열 역매핑: 불가. 정수와 원문 ID의 대응표 또는 복원 규칙이 DB에 없다.
- ID 변환 방식: 각 ID 영역의 원문 값을 정렬한 뒤 `row_number()`로 1부터 연속 번호를 부여하고, 같은 임시 매핑을 관련 PK·FK에 함께 적용했다. 16진수 해석이나 정수 캐스팅은 하지 않았다.
- 외부 계보 키: `UserSynthetic.source_session_id`는 1,000명 기준 DB와의 연결을 위해 TEXT로 유지됐다. 원문 계보를 보존하지 않는 배포본이 필요하면 제거 여부를 별도로 결정해야 한다.

## 전체 문자열 처리

- 기존 DB TEXT 전체 순차 읽기: 23.135초, 24,082,354개 값, RSS 증가 약 1.98 MiB.
- 경량 DB TEXT 전체 순차 읽기: 5.542초, 4,767,452개 값, RSS 증가 약 1.76 MiB.
- 두 결과는 같은 문자열을 역매핑한 비교가 아니다. 경량본에서 ID 문자열이 제거됐기 때문에 읽을 TEXT 값 자체가 적다.
- 사전 테이블이 없으므로 전체 문자열 역매핑 시간은 측정 불가다. 판정은 `해당 없음`이다.

## 수정 전 승인받아야 할 사항

1. 정수 ID를 분석용 내부키로 계속 사용할지, 외부 연계 때문에 원래 문자열 ID의 영구 매핑표가 필요한지 결정.
2. `source_session_id` 계보를 유지할지, 원문 계보가 없어야 하는 배포본에서 제거할지 결정.
3. 추가 증강은 현재 10,000명 경량 결과를 입력으로 사용하지 않고 기준 DB와 확인된 생성기에서 다시 실행하는 것을 원칙으로 확정.
4. `event_type`을 정수 코드화할 경우 고정 코드표와 신규 이벤트 처리 정책을 승인.
5. 시간 TEXT를 epoch 정수로 바꿀 경우 시간대·정밀도·Power BI 변환 계약을 승인.

이 진단에서는 DB 구조와 생성 코드를 변경하지 않았다. 생성기·매니페스트·경량화 스크립트를 추가 확인해 문서 판정만 보완했다.
