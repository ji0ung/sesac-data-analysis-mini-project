# 교육과제 관리 안내

교육과제는 제출 주체와 생성일을 기준으로 정리한다.

- `팀과제/YYYY/MM/`: 2팀 공동 작성 및 제출 자료
- `개인과제/YYYY/MM/`: 개인 작성과 제출이 명확한 자료
- `제공자료/YYYY/MM/`: 강의교안, 문제지, 원본 해답과 양식
- `이전버전/`: 현재 기준에서 내려온 팀·개인 과제

개인 과제와 팀 과제를 구분할 근거가 부족한 기존 파일은 임의로 분류하지 않는다. 파일명에는 `YYYYMMDD`, `vNN`, 상태를 사용하며 다운로드 중복 표기인 `(1)`, `(2)`는 사용하지 않는다.

현재 분석 가설과 분석 결과의 기준본은 `../04_분석설계/`, 발표 기준본은 `../05_발표자료/`에서 관리한다.
