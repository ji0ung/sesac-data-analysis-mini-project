# 데이터 콘솔 최종 명세

관리자 콘솔과 CSV는 아래 8개 데이터셋을 제공한다. 모든 테이블에는 값의 성격을 설명하는 `data_origin`(데이터 구분) 컬럼이 추가된다. 콘솔 상단의 `전체 CSV 한 번에 다운로드` 버튼으로 8개 CSV를 연속 다운로드할 수 있으며, 각 테이블의 개별 다운로드도 유지한다.

`EVENT.session_end_time`은 해당 이벤트가 속한 세션의 종료 시각이다. 신규 자료는 브라우저 `pagehide` 신호 또는 직접 로그아웃 시각을 사용한다. 기존 자료에는 실제 창 종료 기록이 없으므로 세션의 마지막 EVENT 시각을 추정값으로 반영한다. 브라우저 강제 종료나 네트워크 단절 때는 신규 자료도 값이 비어 있을 수 있다.

## HOTEL

`hotel_id, hotel_name, city_name, grade, hotel_address, user_rating, review_count, property_type, actual_address, actual_city, actual_prefecture, actual_postal_code, actual_latitude, actual_longitude, actual_phone, actual_star_rating, supplier_hotel_code, rtx_code, agoda_code, expedia_code, top_selling_rank, source_last_mapped_at, actual_data_sources, data_origin`

## ROOM

`room_id, hotel_id, guest_count, room_count, room_options, pay_later_flag, free_cancel_flag, room_price, room_type, data_origin`

## SEARCH

`search_id, session_id, search_time, query_text, checkin_date, checkout_date, total_result_count, sort_option, guest_count, destination, data_origin`

## SEARCH_FILTER

`search_filter_id, search_id, property_type, property_grade, user_rating_min, price, amenity_count, region, data_origin`

## USER

`user_id, user_name, age_group, email, signup_at, data_origin`

## EVENT

`event_id, session_id, event_type, event_at, hotel_id, search_filter_id, search_id, user_id, rating, review_completed_at, review_text, device, data_origin`

## SEARCH_RESULT

`search_result_id, search_id, hotel_id, room_id, result_score, result_rank, price_rank, data_origin`

## BOOKING

`booking_id, user_id, hotel_id, room_id, booking_status, booking_amount, booking_at, checkin_date, checkout_date, guest_count, room_count, cancellation_deadline, data_origin`

## 콘솔 기능

- 테이블별 CSV 다운로드
- 전체 검색과 사용자 필터
- 개별 컬럼 필터
- 개별·다중·필터 결과 전체 선택
- 삭제 전 2회 확인
- 휴지통 이동과 복구
- 사용자·세션별 USER JOURNEY 확인
- 데이터 콘솔 진입 코드 검증
