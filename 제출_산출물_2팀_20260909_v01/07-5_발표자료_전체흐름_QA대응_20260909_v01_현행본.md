# 발표 자료 전체 흐름

Q&A는 개별 질문을 외우기보다, 발표 전체를 아래 흐름으로 설명할 수 있도록 준비하는 것이 좋습니다.

## 1. 분석의 출발점

이 프로젝트는 일본 여행을 준비하는 한국인의 호텔 검색에서 **결과가 0건인 상황과 그 이후의 회복 행동**을 분석했습니다.

원본 데이터에서는 전체 검색 296건 중 147건, 49.7%가 결과 0건이었습니다. 이 가운데 140건, 95.2%가 다시 검색으로 이어졌지만 바로 다음 검색에서 결과가 회복된 경우는 24건, 17.1%였습니다. 호텔 상세 진입은 14건으로 후속 검색 전이 대비 10.0%였습니다.

핵심 문제는 사용자가 재검색을 포기한다는 것이 아니라, **재검색을 계속해도 결과 회복과 호텔 상세 탐색까지 충분히 이어지지 않는다는 점**입니다.

## 2. 원본 데이터와 집계 기준

원본 데이터는 다음과 같습니다.

- 사용자 41명
- 검색 세션 43개
- 검색 296건
- 결과 0건 검색 147건
- 0건 이후 후속 검색 전이 140건

`검색 전이`는 같은 세션 안에서 결과가 0건인 검색과 바로 다음 검색을 한 쌍으로 묶은 단위입니다.

140개 전이는 다음 6개 재검색 유형으로 중복 없이 분류했습니다.

- 지역 변경 24건
- 조건 완화 41건
- 검색어 수정 10건
- 동일조건 반복 53건
- 조건 강화 10건
- 혼합 변경 2건

합계는 140건입니다. 6번 슬라이드에는 이 가운데 회복이 관측된 세 유형만 표시했습니다.

## 3. 지표의 차이

발표에서 가장 혼동하기 쉬운 부분입니다.

- **재검색 전환율:** 결과 0건 검색 중 다음 검색으로 이어진 비율
  - `140/147 = 95.2%`
- **즉시 회복률:** 0건 직후 다음 검색에서 결과가 1건 이상 나온 비율
  - 전체 `24/140 = 17.1%`
- **세션 최종 회복률:** 결과 0건을 경험한 세션 중 종료 전까지 결과가 회복된 비율
- **0건 후 전이 대비 상세 진입률:** 0건 후 후속 검색 전이 중 호텔 상세 진입이 발생한 비율
  - 원본 기준 `14/140 = 10.0%`
- **결과 있음 검색 대비 상세 진입률:** 결과가 있는 검색 중 상세 진입이 발생한 비율

즉시 회복률과 세션 최종 회복률은 분석 단위와 관찰 범위가 다릅니다. 10번과 12번의 상세 진입률도 분모가 다르므로 같은 지표로 직접 비교해서는 안 됩니다.

## 4. 원본 데이터에서 관찰된 행동 차이

원본 데이터의 재검색 유형별 즉시 회복률은 다음과 같습니다.

- 지역 변경: `10/24 = 41.7%`
- 검색어 수정: `3/10 = 30.0%`
- 조건 완화: `11/41 = 26.8%`

지역 변경에서 가장 높은 회복률이 관찰됐지만, 지역 변경 표본은 24건에 불과합니다. 또한 사용자가 직접 재검색 방법을 선택했기 때문에 사용자 특성이나 검색 난이도가 결과에 함께 반영됐을 수 있습니다.

따라서 이 결과는 특정 기능의 효과를 증명한 것이 아니라, **어떤 대안을 실제 실험 후보로 검토할지 정하기 위한 탐색적 근거**입니다.

## 5. 합성 데이터의 역할

1,000명과 10,000명 합성 데이터는 실제 사용자가 추가된 데이터가 아닙니다. 원본 데이터의 구조와 행동 패턴을 바탕으로 만든 시뮬레이션 자료입니다.

합성 데이터의 목적은 다음과 같습니다.

- 지표 계산 구조 확인
- 세그먼트별 결과 비교
- 실험군과 대조군 구조 점검
- 실제 A/B 테스트 전에 측정 방향 확인

표본 수가 커졌다고 실제 효과의 신뢰도가 높아지는 것은 아닙니다. 합성 데이터만으로 대표성이나 인과관계를 증명할 수 없습니다.

## 6. 세 가지 가설의 결론

### 가격 범위 확대

가격을 설정한 검색의 결과 0건률은 47.2%로 높았지만, 즉시 회복률은 가격 유지군 19.6%, 완화군 17.5%였습니다. 완화군이 유지군보다 2.0%포인트 낮아 **합성 데이터에서는 가격 완화 가설이 지지되지 않았습니다.**

가격 설정 사용자가 많고 실험 대상을 명확히 정의할 수 있다는 점에서 실험 후보로 남긴 것입니다.

### 요구 옵션 수 감소

옵션 3개 설정 검색의 45.8%가 결과 0건이었습니다. 그러나 옵션 수별 즉시 회복률은 18.3~20.8%로 큰 차이가 없었고, 옵션 3개 설정군이 20.8%로 가장 높았습니다.

현재 관측 결과만으로 옵션을 줄이면 회복률이 높아진다고 판단할 수 없습니다. 옵션이 많은 사용자를 대상으로 일부 옵션 해제를 실제로 노출하는 실험이 필요합니다.

### 인접지역 확대

1,000명 합성 데이터에서 지역 비교가 가능한 전이는 2,639건이었고, 지역 변경 전이는 492건으로 18.6%였습니다.

- 지역 변경군 즉시 회복률: 42.7%
- 지역 유지군 즉시 회복률: 13.0%
- 차이: 29.7%포인트
- 상세 진입률: 9.6%와 9.8%

지역 변경군에서 즉시 회복률은 높았지만 상세 탐색 증가는 확인되지 않았습니다. 자발적으로 지역을 변경한 사용자의 관측값이므로, 인접지역 제안 기능의 효과로 단정할 수 없습니다.

## 7. 복합 시뮬레이션 해석

10,000명 합성 데이터의 복합 개선 시나리오에서는 다음 변화가 나타났습니다.

- 검색 0건률: 6.34%포인트 감소
- 즉시 회복률: 5.12%포인트 증가
- 세션 최종 회복률: 6.71%포인트 증가
- 상세 진입률: 0.27%포인트 감소

검색 결과 회복 관련 지표는 개선됐지만 상세 진입까지 이어지지는 않았습니다. 가격·옵션·지역 조건을 함께 조정한 결과이므로 어느 기능이 변화를 만들었는지 구분할 수 없습니다.

이 결과는 실제 효과의 증명이 아니라, **측정 지표의 변화 방향과 실험 구조를 점검한 결과**입니다.

## 8. 전략으로 연결되는 이유

세 가지 대안은 현재 바로 적용할 기능이 아니라 **실제 A/B 테스트 후보**입니다.

- 가격 설정 사용자: 가격 범위 확대 또는 해제 제안
- 옵션이 많은 사용자: 일부 옵션을 단계적으로 해제하도록 제안
- 위치 유연형 사용자: 인접 도시나 대체 지역 제안

세 기능을 동시에 적용하면 효과의 원인을 구분할 수 없으므로 기능별로 대조군과 실험군을 분리해야 합니다.

주요 측정 지표는 다음과 같습니다.

- 검색 0건률 - 분자 : 결과가 0건인 검색 수, 분모 : 전체 검색 수
- 즉시 회복률 - 결과 0건 직후의 바로 다음 검색에서 결과가 1건 이상 나온 비율, 분자 : 즉시 회복 전이 수 , 분모 : 0건 후 후속 검색 전이 수
- 세션 최종 회복률 - 결과 0건을 경험한 세션이 종료 전까지 회복된 비율, 분자 : 최종 회복 세션 수, 분모 : 0건 경험 세션 수
- 상세 진입률 - 분자 : 호텔 상세 진입이 발생한 후속 검색 전이 수, 분모 : 0건 후 후속 검색 전이 수
- 지속 실패율 - 분자 : 0건 직후 다음 검색에서도 결과가 0건인 전이 수, 분모 : 0건 후 후속 검색 전이 수
- 향후 확보할 예약 전환율

## 9. 사용자 세그먼트의 의미

같은 결과 0건 경험자라도 이후 행동이 다르기 때문에 모든 사용자에게 동일한 안내를 제공하는 것은 적절하지 않습니다.

- 조건 고수형: 완화했을 때 확보되는 추가 결과 수 안내
- 위치 유연형: 인접지역 추천
- 복합 변경형: 조건을 단계적으로 비교하도록 안내
- 예산·옵션 유연형: 가격 확대에 따른 결과 수 제시
- 후속 행동 미관측 사용자: 유사 조건이나 인기 지역으로 탐색 유도

세그먼트는 사용자를 고정된 성향으로 단정하기 위한 분류가 아니라, **어떤 안내를 먼저 실험할지 구분하기 위한 행동 기반 분류**입니다.

## 10. 한계와 다음 실행

현재 데이터로 확인할 수 없는 부분은 명확합니다.

- 원본 사용자 41명이 전체 이용자를 대표하는지
- 제안 기능이 실제로 회복률을 높이는지
- 추가 검색이 없는 사용자가 실제로 이탈했는지
- 검색 회복이 예약 전환으로 이어지는지
- 합성 데이터 결과가 실제 서비스에서도 재현되는지

다음 단계에서는 가격·옵션·지역 기능을 각각 분리한 실제 A/B 테스트를 진행해야 합니다. 제안 노출, 선택, 조건 변경, 결과 회복, 상세 진입, 예약까지 연결되는 로그도 수집해야 합니다.

발표 전체의 결론은 다음 문장으로 정리할 수 있습니다.

> 원본 로그에서 재검색 방법별 회복률 차이는 관찰됐지만, 특정 안내의 실제 효과는 아직 확인되지 않았습니다. 가격·옵션·지역 대안을 사용자 유형별로 나눠 실제 A/B 테스트로 검증하는 것이 다음 단계입니다.

현재 슬라이드 전체 흐름에서 파악되는 청중은 **서비스를 이용하는 사용자**와 **분석 결과를 실행하는 실무자**로 나눌 수 있습니다.

| 검색·추천 담당자 | 검색 조건, 필터와 추천 로직을 개발하는 담당자 | 가격·옵션·지역 대안의 노출 조건과 우선순위 |
| 데이터 분석가 | 검색 행동과 실험 결과를 측정하는 담당자 | 지표 정의, 분석 단위, 분자·분모와 A/B 테스트 구조 |

발표의 핵심 의사결정 청중은 다음과 같이 정리할 수 있습니다.

> **검색 결과 0건 화면을 개선할 서비스 기획자와 검색·추천 담당자**

최종 사용자는 일본 여행객이지만, 발표 결과를 실제 기능으로 옮기는 사람은 서비스 기획자와 개발·분석 담당자입니다.

## 청중이 결정해야 할 내용

이 발표를 통해 청중이 결정해야 하는 것은 다음과 같습니다.

> 검색 결과가 0건일 때 가격·옵션·지역 중 어떤 대안을 누구에게 먼저 실험할 것인가?

현재 분석만으로 특정 기능을 바로 적용하는 결정을 내리기는 어렵습니다. 따라서 세 가지 기능을 **실제 실험 후보로 승인하고, 각각 분리해 검증하는 결정**이 필요합니다.

## 실험 운영 방식

세 기능을 동시에 적용하면 어떤 기능이 결과에 영향을 주었는지 구분하기 어렵습니다. 따라서 기능별로 실험을 분리해야 합니다.

1. 대상 조건을 충족한 사용자를 선별합니다.
2. 사용자를 대조군과 실험군에 무작위로 배정합니다.
3. 실험군에만 해당 대안을 노출합니다.
4. 제안 노출부터 선택, 조건 변경, 결과 회복까지 연결해 기록합니다.
5. 상세 진입과 예약 전환까지 후속 행동을 확인합니다.
6. 기능별 효과를 비교한 뒤 적용 여부와 노출 우선순위를 결정합니다.

## 우선순위 해석

현재 결과만으로 지역 기능을 가장 효과적인 기능이라고 확정할 수는 없습니다. 다만 원본 로그에서 지역 변경의 즉시 회복률이 41.7%로 가장 높게 관찰됐고, 1,000명 합성 데이터에서도 지역 변경군과 유지군의 차이가 나타났습니다.

따라서 실행 순서는 다음처럼 제시할 수 있습니다.

| 순서 | 실행 내용 | 이유 |
|---:|---|---|
| 1 | 인접지역 제안 A/B 테스트 | 원본과 합성 데이터에서 일관된 관측 차이가 있었지만 인과효과는 미검증 |
| 2 | 옵션 단계적 해제 A/B 테스트 | 옵션 수만으로는 회복률 차이가 작아 실제 제안 효과를 별도로 확인해야 함 |
| 3 | 가격 범위 확대 A/B 테스트 | 합성 데이터에서 가격 완화군이 유지군보다 낮아 적용 전에 재검증 필요 |

이 순서는 기능 적용 순위가 아니라 **실험 진행 순위**입니다.

발표에서는 다음 문장으로 정리하면 좋습니다.

> 이번 분석의 주요 청중은 검색 결과 0건 화면을 개선하는 서비스 기획자와 검색·추천 담당자입니다. 세 가지 대안을 바로 적용하기보다 사용자 유형별로 분리한 A/B 테스트를 진행하고, 즉시 회복률과 상세 진입률, 예약 전환율을 확인한 뒤 실제 적용 여부를 결정하는 것이 실행안입니다.
