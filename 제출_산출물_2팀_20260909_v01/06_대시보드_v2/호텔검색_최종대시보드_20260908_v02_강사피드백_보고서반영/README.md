# 호텔검색 대시보드 v02

v01을 보존한 별도 버전입니다. 강사 피드백과 최종 보고서, 탐색용 10,000명 SQLite를 반영했습니다. index.html은 인터넷 없이 열 수 있습니다.

## 화면 구성

- 00 주제·전체 요약: 주제·문제·목적 설명, 원시→1,000명→10,000명 과정 표.
- 01 전체 현황·검색 경험: 최신 10,000명 직접 집계. 검색량·참여자·시작 세션, 검색어 주제 버블, 초기 조건과 검색 경험, 회복 퍼널, 4개 세그먼트별 경로 비교.
- 02 가설: 실제 검증 질문과 연결 가능한 합성 근거를 구분.
- 03 A/B: 8개 지표, 14개 사전 조건군, 기준선·불확실성·HOLD.
- 04 핵심 발견·의사결정: 파일럿 계측과 기능별 검증 계획.
- 05 목표 KPI·시뮬레이션: 0건 감소→상세 진입→검색 귀속 예약. 목표 비율·검색량을 입력해 결과와 필요한 확장량을 계산하고 가드레일을 확인.

## 해석 범위

검색어 주제군은 business/family/weekend/hotel/stay의 의미 기반 가분류입니다. 실제 사용자 의도나 기존 6개 조건 변경 의도군 배정이 아닙니다. 검색 후 종료는 다음 검색이 없는 것으로 실제 이탈을 뜻하지 않습니다. 예약 데이터는 없어 예약률은 직접 입력하는 가정이며 0%로 표시하지 않습니다. 시뮬레이션의 필요한 검색량은 트래픽 수요 역산이고 실제 A/B 표본 수나 합성 생성량이 아닙니다.

시간축은 합성 2028-02-01~02-07 UTC이며 마지막 날은 03:47:37까지만 포함합니다. strict calibration HOLD와 교육·발표·탐색용 제한 사용을 유지합니다.

## 수정·재생성

- src/dashboard.html, src/dashboard.css, src/dashboard.js: 공통 화면·동작.
- src/kpi.html, src/planning.js: 05 계산기와 세그먼트 경로 전환.
- scripts/overview.py, data/overview_10000.json: 전체 현황.
- scripts/exploratory.py, data/exploratory_10000.json: A/B 집계.
- scripts/aggregate_overview.py: 저장소 루트에서 실행. SHA 확인 후 SQLite를 읽기 전용 집계합니다. Git LFS 객체도 지원합니다.
- scripts/build.py 실행 후 --check로 index.html 동기화를 확인합니다. index.html은 직접 수정하지 않습니다.

검증: DB 사용자·검색·세그먼트·검색 종료 합계 대조, 6개 탭과 17장 슬라이드, 예약률 공란·0%·잘못된 입력, 목표 역산, 가드레일, 4개 검색 경로 지표, 모바일 화면을 확인했습니다.


최신 화면: 03은 핵심4지표 막대/일별 C·T 선그래프, 05는 실패율 상대5·10·15% 감소의 고정 시뮬레이션입니다. 입력 계산기·예약 가정·03의1,000명 참고 비교는 제거했습니다. 02의 가설 상태·사유와04의 사용자 이탈 측정 한계를 확인하세요.
