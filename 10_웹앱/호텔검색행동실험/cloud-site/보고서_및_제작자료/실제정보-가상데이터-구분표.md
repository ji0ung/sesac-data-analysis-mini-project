# 실제 정보와 가상 데이터 구분

| 분류 | 항목 | 출처와 처리 방식 |
|---|---|---|
| 실시간 실제 정보 | 상세 화면 숙소명, 주소, 좌표, 숙소 유형, 원본 지도 링크 | Google Places를 우선 조회하고 권한·매칭 문제 시 OpenStreetMap Nominatim으로 대체한다. 장기 저장하지 않는다. |
| 조건부 실제 정보 | 플랫폼 평점·평가 수, 운영 상태, 공식 웹사이트 | 실제 조회 출처가 제공할 때만 표시한다. 제공되지 않으면 빈값 또는 제공되지 않음으로 표시한다. |
| 공개자료 참고 | 검색 목록 호텔명과 도시 | 기존 관광 디렉터리와 2026-08-27 OpenStreetMap 숙박업소 명칭을 참고했다. 개별 실시간 확인 전에는 참고값이다. |
| 가상 데이터 | 세부지역, 등급, 10점 평점, 리뷰 수, 가격, 역 거리, 편의시설 | 연구 목적의 규칙 기반 시뮬레이션이다. |
| 가상 객실·예약 | 객실 유형·면적·침대·전망, 재고, 취소·결제 정책, 예약 금액·상태 | 실제 숙박 재고나 결제 시스템과 연결되지 않는다. |
| 가상 콘텐츠 | 대표 리뷰 5개, 대표·시설·객실 이미지 | 호텔 특성을 반영해 생성한 연구용 콘텐츠이며 실제 후기나 호텔 사진이 아니다. |
| 실제 연구 로그 | 참여자 입력, 검색, 필터 적용, 클릭, 상세 조회, 객실 선택 | 참여자가 사이트에서 실제로 수행한 행동이다. 예약 완료는 실제 거래가 아니라 시뮬레이션 완료 이벤트다. |

## 주의사항

- 실시간 검색 결과가 없으면 실제값을 임의 생성하지 않는다.
- Google API 키는 현재 권한 문제로 거부될 수 있으며 이 경우 OpenStreetMap 실제 정보가 표시된다.
- 가격·객실 재고·예약 정책을 실제화하려면 별도의 호텔 예약 공급사 API 계약이 필요하다.
- 검색 오류와 객실 옵션 불일치는 연구를 위해 의도적으로 삽입된 실험 조건이다.
# 사용자 제공 일본 호텔 자료 보강(2026-08-28)

- 실제 제공자료: 호텔명, 주소, 도시·도도부현, 우편번호, 위도·경도, 전화번호, 성급, 공급사/RTX/Agoda/Expedia 코드, 기록된 판매 순위와 매핑일(호텔별 제공 여부가 다름)
- 가상 유지: 가격, 이용자 평점, 리뷰 수·본문, 편의시설, 객실 옵션, 재고, 예약 가능 여부
- 매칭 방법: 기존 호텔명과 정규화된 정확 이름 일치. 유사 이름 자동 추정은 하지 않음.
- 반영 범위: 기존 1,000개 중 491개. 나머지는 기존 공개자료 참고 호텔명과 연구용 가상 속성을 유지함.
