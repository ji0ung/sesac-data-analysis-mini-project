# 날짜·시간 한국 표준

사이트에서 생성되는 행동 로그, 사용자 등록, 세션 시작·종료, 검색, 예약, 삭제 기록은 한국 표준시(`Asia/Seoul`)를 사용한다.

- 저장 형식: `YYYY-MM-DDTHH:mm:ss+09:00`
- 관리자 화면·CSV 형식: `YYYY-MM-DD HH:mm:ss KST`
- 날짜만 필요한 체크인·체크아웃: `YYYY-MM-DD`

기존 UTC 기록도 배포 시 포함되는 데이터베이스 마이그레이션으로 한국 표준시로 변환한다. 단순히 숫자만 바꾸는 것이 아니라 기존 기록이 가리키는 실제 순간을 보존하며, 신규 기록도 동일한 규칙으로 저장한다.
