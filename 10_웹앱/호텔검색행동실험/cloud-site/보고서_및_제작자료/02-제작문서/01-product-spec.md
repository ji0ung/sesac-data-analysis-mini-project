# 제품 및 제작 명세

## 1. 목적

StayTrace는 사용자가 호텔을 검색하고 결과를 비교한 뒤 상세 페이지와 객실 상품을 확인하고 예약 여부를 결정하는 과정을 관찰하는 연구용 웹앱이다. 핵심 연구 질문은 검색 의도와 노출 결과 또는 예약 가능한 객실 조건이 불일치할 때 재검색, 이탈, 객실 선택, 예약 전환이 어떻게 달라지는가이다.

실제 숙박 예약 서비스가 아니며 결제 기능은 제공하지 않는다.

## 2. 대상 사용자

- 연구 참여자: 로그인 계정 대신 이름과 인구통계 정보를 입력한다.
- 연구 관리자: 누적 데이터, 이벤트 경로, KPI, 삭제·복구 상태를 확인하고 CSV를 내려받는다.

동일한 이름은 동일 사용자로 처리한다. 로그인 정보는 탭을 닫기 전까지 유지하는 `sessionStorage` 성격의 세션을 사용한다.

## 3. 화면 흐름

1. 참여자 정보 입력
2. 최소 검색창: 검색어, 지역(초기 미선택), 세부지역, 날짜, 인원, 객실 수
3. 검색 버튼 제출
4. 검색결과와 별도 스크롤 상세 옵션 패널
5. 호텔 카드 또는 대표 이미지 클릭
6. 호텔 안내 상세, 시설 이미지 갤러리, 리뷰, 객실 상품
7. 객실 선택 및 예약 확인
8. 찜 목록 확인과 객실 상품 장바구니 담기·삭제·예약 진행
8. 예약 완료 또는 취소 후 이전 검색·상세 상태 복귀

상세 옵션에서 날짜와 인원은 변경할 수 없으며 최초 검색 영역에서만 바꾼다. 옵션값은 입력 즉시 결과에 반영하지 않고 `선택 옵션 적용` 버튼을 눌렀을 때 새 검색으로 반영한다.

## 4. 검색 기능

데이터 출처 표시는 모든 호텔 카드와 상세 화면에 제공한다. 상세 진입 시 Google Places API에서 실제 숙소 정보를 조회하고, 키 권한 또는 매칭 문제 시 OpenStreetMap Nominatim 실시간 조회로 대체한다. 출처가 제공하지 않는 평점·평가 수는 실제값처럼 생성하지 않는다. 가격·객실·시설·재고·예약 정책·생성 이미지·대표 리뷰는 연구용 가상 데이터로 표시하며, 관리자 CSV에는 `data_origin` 칼럼을 포함한다.

- 한글·영문 검색어 정규화
- 도시와 세부지역
- 날짜, 성인·아동 수, 객실 수
- 숙소 유형, 등급, 평점, 가격 구간과 최대 가격
- 역 거리, 취소·결제 정책, 조식
- 가족 객실, 반려동물, 수영장, 스파, 발코니, 욕조, 금연 등
- 별점 높은 순, 리뷰 많은 순, 가격 낮은 순, 가격 높은 순 정렬
- 페이지네이션 및 카드 이미지 탐색

검색은 버튼 클릭 시에만 저장된다. 키 입력 하나하나 또는 체크박스 변경 자체를 검색 제출 이벤트로 기록하지 않는다.

## 5. 호텔 상세

- 실제 호텔명 기반 기본 정보와 세부지역
- 임의 점수로 호텔 상태를 평가하지 않는 안내 중심 설명
- 대표 이미지와 시설별 이미지 8장
- 평점, 리뷰 수, 가상 대표 리뷰 5개
- 호텔·객실 시설을 구분해 표시
- 날짜별 판매 마감 여부가 포함된 객실 3종
- 고정된 이전 화면 버튼

## 6. 관리자 기능

- HOTEL, ROOM, SEARCH, SEARCH_FILTER, USER, EVENT, SEARCH_RESULT, BOOKING 테이블
- 표 검색 및 전체 열 확인
- 테이블별 CSV 다운로드
- 행 소프트 삭제, 휴지통 확인, 복구
- 사용자·검색어·테이블 필터와 모든 데이터 칼럼별 동시 필터, 다중 선택, 필터 결과 전체 선택, 일괄 삭제·복구
- 필터 결과를 선택 단계 없이 바로 일괄 삭제하는 기능
- 사용자 선택 후 로그인 세션별 이벤트를 시간순으로 보는 USER JOURNEY 탭
- 검색 효율, 상세 진입, 객실 선택, 예약 시작·완료 지표
- 본 제작 보고서 다운로드

## 7. 비기능 요구사항

- 모바일과 데스크톱 반응형 화면
- 링크가 있으면 로그인 없이 누구나 접근하는 공개 배포
- 사용자의 PC를 꺼도 동작하는 클라우드 호스팅
- 버튼과 이미지에 접근 가능한 이름 제공
- 동일 세션·조건의 실험 결과 재현 가능
- 데이터 저장 성공 이후 화면 상태 갱신
- 비밀 키를 브라우저 코드 또는 Git 저장소에 포함하지 않음

## 8. 완료 기준

- 검색, 필터, 정렬, 상세, 뒤로가기, 찜, 객실, 예약 모의 흐름 동작
- 검색 버튼마다 고유 search_id 생성 및 parent_search_id 연결
- 세션 내 행동을 시간순으로 복원 가능
- 호텔 노출 순위와 오류 노출을 이벤트로 구분 가능
- 관리자 콘솔과 CSV가 같은 원천 데이터를 반영
- 프로덕션 빌드 성공 및 공개 URL 응답 확인
