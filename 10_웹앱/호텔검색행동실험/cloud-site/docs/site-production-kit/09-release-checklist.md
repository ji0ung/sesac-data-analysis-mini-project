# 배포 전후 체크리스트

## 코드와 데이터

- [ ] 기존 사용자 변경사항을 덮어쓰지 않았다.
- [ ] 타입과 DB 컬럼명이 일치한다.
- [ ] 새 필터가 UI·API·저장·CSV·오류 실험에 모두 연결됐다.
- [ ] 호텔 수, 리뷰 수, 객실 수와 중복 ID를 확인했다.
- [ ] migration은 추가형이며 기존 데이터와 호환된다.
- [ ] API 키와 토큰이 Git diff에 없다.

## 행동 로그

- [ ] 검색 제출은 버튼당 한 번이다.
- [ ] 재검색은 새 search_id와 parent_id를 가진다.
- [ ] 호텔 impression은 검색 ID, 호텔 ID, rank를 가진다.
- [ ] 상세·뒤로가기·갤러리·객실·예약 이벤트가 중복되지 않는다.
- [ ] 오류 노출 이벤트에 variant와 오류 세부정보가 있다.
- [ ] 취소 후 이전 상태가 유지된다.

## 화면

- [ ] 최초 검색 지역이 미선택이다.
- [ ] 한글 검색과 지역 없는 검색이 동작한다.
- [ ] 상세 옵션은 적용 버튼 전까지 결과를 바꾸지 않는다.
- [ ] 옵션 패널과 호텔 목록이 독립 스크롤된다.
- [ ] 고정 뒤로가기 버튼이 스크롤 중 보인다.
- [ ] 모바일에서 검색, 상세, 객실, 관리자 기능을 사용할 수 있다.
- [ ] 실제 데이터와 시뮬레이션 데이터 안내가 보인다.

## 검증과 배포

- [ ] 프로덕션 빌드가 성공했다.
- [ ] 기존 Sites project_id를 재사용한다.
- [ ] 빌드한 소스와 배포 커밋이 동일하다.
- [ ] 공개 접근 정책을 보존했다.
- [ ] 배포 상태가 succeeded다.
- [ ] 사용자 URL과 보고서 URL이 HTTP 200이다.
- [ ] 제작 문서 ZIP 또는 폴더 링크가 최신이다.

## 연구 시작 전

- [ ] 참여 동의·개인정보·보관 기간을 확정했다.
- [ ] 조사 회차와 배포 버전을 기록했다.
- [ ] 정상군/오류군 비율을 기록했다.
- [ ] 기준 데이터와 빈 로그 상태를 백업했다.
- [ ] 관리자 접근 통제 필요 여부를 결정했다.
