# 한국 표준시 날짜·시간 규칙

StayTrace의 행동 로그와 생성·종료·예약·삭제 시각은 한국 표준시 `Asia/Seoul`을 기준으로 한다.

- 데이터베이스 저장: `YYYY-MM-DDTHH:mm:ss+09:00`
- 관리자 화면과 CSV: `YYYY-MM-DD HH:mm:ss KST`
- 체크인·체크아웃처럼 시각이 없는 날짜: `YYYY-MM-DD`

기존 UTC 데이터는 `0005_korean_standard_time.sql` 마이그레이션에서 같은 순간을 유지한 채 9시간을 더하고 `+09:00` 오프셋을 명시한다. `Z`로 끝나는 기존 값만 변환하므로 재실행해도 이미 변환된 값은 다시 바뀌지 않는다.

신규 기록은 서버 실행 지역이나 사용자 브라우저의 시간대와 관계없이 `+09:00` 형식으로 생성한다. 화면과 CSV 응답에서도 `Asia/Seoul`을 명시해 해외에서 접속하더라도 같은 시각을 보여 준다.
